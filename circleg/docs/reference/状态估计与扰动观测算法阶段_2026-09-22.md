# 状态估计、控制监督与扰动观测算法阶段

日期：2026-09-22。用户已批准先写算法，并增加 RLS、ESO、广义动量观测。
本阶段不调参、不接入 MuJoCo 或实机；仿真接入仍由用户另行决定。

## 1. 本阶段实现及证据链

| 原问题/需求 | 原有源码证据 | 当前算法行为 |
|---|---|---|
| 原始轮速含父连杆运动 | estimator.py 只对轮编码器差分乘半径，髋角只用于噪声调度 | 新 CrankWheelOdometry 补偿曲柄角速度、机身角速度与轮心平移；逐轮接触/滑移决定观测有效性 |
| 速度估计没有加速度零偏状态 | 旧滤波状态为 pitch/pitch_rate/v | 独立 VelocityBiasKalman 使用 v/a/b，缺测时只传播过程不确定度；ProprioceptiveVelocityEstimator 组合运动学与滤波 |
| reference.valid 只在参考层生效 | WheelMPC.solve 是低层求解入口，仍会自行求解 | 新 SupervisedControl 用统一 ControlDecision 门控 MPC 与 WBC，暂停时不求 MPC，恢复沿重置参考 |
| 单轮失接触后的执行权限未统一 | 原先只有人工 contact 信号与低层矩阵接口 | 显式 ContactBlock 声明轮归属；单支撑移除失接触块与运动任务，保留调用方提供的平衡任务 |
| WBC 能力反馈未闭合 | JointLoop 未将最终任务残差送回参考层 | WbcFeedbackAccumulator 收集所有 WBC 子步的运动任务最终残差与受限标志，下一 MPC 周期消费，忽略末级正则的独立耗尽 |
| 建模误差与未知外扰 | 无 RLS/ESO/动量模块 | 新增独立模块、有效性/模型版本边界和互斥补偿路由；补偿进入模型方程，最终力矩仍由约束求解 |

所有新算法模块仅依赖 numpy/scipy 及项目算法层。APP 原控制链未接入这些模块，旧 BodyStateKalman 保留，
防止将未验证的新估计路径自动接入正式仿真。这里是算法装配完成，不是应用或实机装配完成。

## 2. 估计量、坐标和量纲

新增轮速估计的参考点 B 是 **base_link 机身坐标系原点**，不是轮轴中点或移动整机质心。
传入实际髋安装点、曲柄长度、轮半径、左右关节轴符号以及轮中心相对轮关节的轴向偏移。
XML 中轮碰撞中心有 -0.01 m 的轴向偏移，偏航补偿不能将其遗漏。

```
p_C = p_B + R r_BC(q)
v_C = v_B + omega_B × (R r_BC) + R J_BC(q) qdot
(v_C + omega_wheel × rho_contact)_tangent = 0
```

其中 omega_wheel 包含机身、曲柄与轮关节的转动。得到 v_B 后投影到水平航向前方。
当前为平地理想圆轮无滑观测；不声称适用于任意侧滚角、轮缘多点接触或复杂地形。
IMU 固定杆臂补偿单独由 InertialAcceleration 提供，显式区分加速度计比力与重力；
活动云台引起的移动质心不属于固定杆臂模型。

反馈行程对融合后的实际速度积分；参考行程仍对规划速度积分，不能混用。
新滤波器采用连续白噪声 jerk 与 bias 随机游走离散化；每轮有效观测分别更新，默认假设条件独立。
共享 IMU/几何误差造成的相关噪声需后续建模，不能仅靠重复两路同源观测宣称置信度更高。

## 3. 三种观测器的分工

### RLS：指定回归模型的慢变参数

模块：`Algorithm/observers/rls.py`。
估计关系为 `y = phi.T theta`；回归量的物理意义由调用方定义，不宣称自动辨识全机质量/惯量。

- 参数边界、遗忘因子、观测方差、激励阈值与激励衰减全部显式配置。
- 缺乏足够独立激励时只收集激励信息，不更新参数，也不通过遗忘无限放大协方差。
- learning_allowed=False 时冻结参数与协方差，激励可信度继续衰减。
- 使用 Joseph 形式协方差更新；触及参数投影边界时不宣称估计可直接采用。
- 滑移、接触切换、未知外力期间必须禁止学习。RLS 无法仅凭残差区分外力与参数误差。

### ESO：速度通道的剩余总扰动

模块：`Algorithm/observers/eso.py`。
使用 `v_dot = a_known + d`、`d_dot = 0`，不对测量速度做数值微分。
已知项必须来自上一采样间隔的实际执行输入及模型，而非未经饱和的请求指令。

离散预测与校正为：

```
v_minus = v_hat + dt * (a_known + d_hat)
e = v_measured - v_minus
rho = exp(-bandwidth * dt)
v_hat = v_minus + (1-rho^2) * e
d_hat = d_hat + (1-rho)^2/dt * e
```

理想单通道误差系统的两个极点均为 rho，dt>0、bandwidth>0 时位于单位圆内。
这只证明所用离散观测误差模型的稳定性，不等价于机器人闭环在噪声/延迟/饱和下必然稳定。
无可信数据或 context 改变时重置，经过显式 warmup 时间才标记有效。
六状态 MPC 对应的三通道顺序为 `[forward acceleration, pitch angular acceleration, yaw angular acceleration]`，
角速度应与 MPC 状态定义一致，不能在大姿态下直接把任意陀螺轴当作 Euler 角速度。

### 广义动量观测：广义外力残差

模块：`Algorithm/observers/momentum.py`。

```
M vdot + h = tau_applied + tau_contact + tau_external
p = M v
pdot = tau_applied + tau_contact - h + Mdot*v + tau_external
```

不需要测量广义加速度，但需要同一广义速度基下的 M、v、h、Mdot*v，实际执行广义力，
以及独立可信的接触广义力。不能漏掉 Mdot*v，也不能用“假设外力为零回代的接触力”反过来证明外力估计正确。
这些模型量必须由后续适配器提供；本阶段没有伪造实际机器人可用的 Coriolis 或接触传感器。

动量增量减去已知冲量后，以隐式离散残差反馈更新：

```
r_k = (r_previous + K * (p_k - p_previous - known_impulse)) / (1 + K*dt)
```

K 为正对角增益。执行器力矩与接触力输入表示上一间隔的实际平均广义力，乘 dt 得冲量；
`Mdot*v-h` 用相邻端点梯形积分。不能对跳变的新旧执行器指令再做端点平均，避免制造虚假外力脉冲。
接触未知或不可信时输出无效并重置；模型/接触 context 改变也重置，冲击时不继续沿用旧积分历史。
观测残差可能仍包含模型误差，并不自动等于某个接触点的独立外力，更不能唯一定位外力作用点。

## 4. 避免重复补偿，以及补偿放在哪里

`AdaptiveAccelerationObserver` 提供三通道 RLS + 剩余扰动 ESO 组合：

1. RLS 在后台按允许条件学习；在线使用的参数副本不随每个样本跳变。
2. 只有显式 commit 且估计具备激励、未处于边界投影时才提交；由调用方确认稳态可靠支撑。
3. 提交后重置 ESO。ESO 的已知项包含已提交的 RLS 预测，因而只估计剩余误差。
4. 输出一次 `RLS_active + ESO_residual`。不再额外叠加广义动量残差。

`DisturbanceEstimate` 标明来源、量纲空间、时间戳、上下文与有效性；`CompensationRouter` 只允许一个显式来源，
检查新鲜度/上下文，限制补偿幅度及有效期间的变化率，失效时立即撤销。
立即撤销意味着失效边界不保证补偿连续；需要整体模式退出管理，不能把限速规则当作所有故障下的连续性证明。

算法装配 `SupervisedControl` 每实例最多配置一个路由：

- **加速度估计进 MPC**：将扰动放入六状态连续漂移的 1/3/5 号分量，经 drift_step_map 离散化。
  状态预推、QP、输出优化轨迹使用同一扰动项，仍执行原有力/姿态/速度约束与兜底。
- **广义外力估计进 WBC**：使用 `h_effective = h - estimated_external_force` 解原有动力学与力矩约束。
  返回解满足 `M*qacc+h = S.T*tau+J.T*f+estimated_external_force`，不在求解后加力矩。
- 两种路径可以并行观察，但该装配不会同时激活两层对同一扰动的补偿。
  未来若需要双层补偿，必须明确残差分解与模型一致性后另行设计。

低层 WheelMPC.solve 与 SaturationResolver.resolve 仍提供纯数学接口；完整权限门控应调用 SupervisedControl，
不能绕过它又声称自动获得模式保护。

## 5. 监督与能力反馈的当前边界

- ContactDetector 使用力阈值滞回和持续时间；触地/离地分别配置。低载荷消抖期间，不保留旧的大法向力预算。
- ControlSupervisor 每拍只做一次优先级决定：失能/过期优先，然后双离地、单支撑、双支撑恢复、正常运动。
  时间必须单调，dt 与实际经过时间一致。接触/模式变化增加 context，供观测器重置。
- 双轮离地或失能：不求 MPC，输出明确零力矩且不伪称获得对应 qacc；当前没有空中主动调姿算法。
- 单支撑：不运行双支撑简化 MPC，WBC 移除离地侧接触块、停止运动任务，保留调用方定义的平衡任务。
- 稳定双支撑恢复：经过配置驻留时间重新对齐参考，不能追赶旧位置。
- WbcFeedbackAccumulator 汇总整个 MPC 间隔，不让最后一个正常 WBC 子步覆盖此前的运动任务受限。
  scaling 只用于识别该运动任务纠正增量受限，结合最终残差才形成参考层降额，不视为速度比例。

现阶段的单支撑测试验证的是行选择、任务权限与等式动力学，未验证真实轮圈腿单轮恢复的物理可行性。
接触法向非负、完整摩擦锥以及接触信号有效性仍需独立实现/验证，SNSResult.feasible 仍不代表这些全部满足。

## 6. 验证记录

完整非 MuJoCo 回归命令：

```
.venv/Scripts/python.exe -m pytest -p no:cacheprovider --ignore=tests/test_mujoco_wbc.py -q -o addopts=
```

最终完整回归：**287 passed，54.22 s**；2810 条 OSQP PendingDeprecationWarning。
本阶段新增 37 项回归，包含执行器保持输入跳变的动量反例。
本阶段未运行既有的 3 项 MuJoCo 矩阵单拍测试，也未运行 MuJoCo 闭环。
新增测试文件：test_observers.py、test_velocity_estimation.py、test_supervision.py、test_disturbance_control.py。

验证覆盖：

- RLS 对独立回归量的已知参数收敛、秩不足不更新、学习禁用、协方差正定及边界投影标志。
- ESO 在 dt=1/20/100 ms 的理想常扰动样例中估计方向与量值正确；使用实际饱和输入不产生虚假扰动。
- 广义动量观测正确扣除已知支撑，变质量 Mdot*v 不被误判为外力，接触切换重置，执行器跳变不制造外力。
- 组合 RLS/ESO 只恢复一次总扰动；模型提交后 warmup 重启。
- 补偿量纲/来源不混用，超时和 context 不匹配撤销，幅值与变化率限制有效。
- 独立有限差分轮心运动生成编码器数据，验证正反向、曲柄运动、机身俯仰和偏航补偿；单轮/无有效轮观测正确门控。
- 合成加速度零偏可分离，无观测时协方差传播而非收缩；反馈行程积分估计速度。
- 接触滞回、事件仲裁、MPC 暂停/恢复、单支撑保留平衡、失能零输出、最终任务残差的跨子步反馈。
- 已知外力下 WBC 全动力学残差 <1e-12 的样例通过，并在执行器饱和时仍返回一致的加速度。
- MPC 已知扰动的状态预推与各预测节点，与独立离散方程逐步展开一致。
- 二自由度解析受约束对象中施加 1 N 未知水平阶跃外力：不补偿时末速度误差 >0.2 m/s；
  分别使用 ESO 或动量补偿后 <0.002 m/s，动力学残差 <1e-10。
  此夹具执行器为水平力源，输出不超过 2 N；其量纲不是实机轮电机的 N·m。
  这是刻意简化的数学夹具，绝不代表本机器人已经获得同样的抗扰性能。
- 原有多频率速度跟踪、停车与反向回归继续保留，厘米级有界停车残差仍不作为调参目标。

## 7. 参数与未完成事项

未改变既有 MPC 权重、WBC 增益、运动限值。新观测器/监督/滤波参数要求显式传入；
测试样例中的质量、带宽、噪声、门限仅用于证明数学行为，没有作为 APP 默认配置启用。

后续仍需用户决定并审批仿真接入，然后才能验证：

1. 实际 M/h/Mdot*v、执行器已施加力矩、可靠接触力与时间戳的来源及模型基一致性。
2. 真实回归量的可辨识性、外扰期间学习冻结策略、RLS 提交边界；参数估计不等价于物理真值。
3. 传感器噪声、偏置、延迟、离散模型误差下的观测收敛与补偿稳定裕度；本阶段未调带宽。
4. 完整单边/摩擦约束和接触模式切换；单支撑恢复与腾空策略的实物权限。
5. 实际髋部工作点、不同曲柄角下的模型调度以及原有髋力矩漂移符号。
6. APP 装配、新估计器替换、传感器丢失处理与端到端运行性能。

当前结论应表述为“上述算法实现通过规定的数学/解析回归”，不能表述为“所有机器人控制问题已排除”。
