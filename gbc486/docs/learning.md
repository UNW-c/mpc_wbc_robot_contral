# 学习路线

这份文档给第一次接触这个项目的人一条阅读路径。目标不是“看完所有代码”，而是理解三层东西：

1. 这台机器人的机构和状态是怎么定义的；
2. MPC 和 WBC 各自解决什么问题、边界在哪里；
3. 跳跃为什么必须用两个质量块，而不是腿长和摆角。

前置知识：刚体动力学（`M q̈ + h = τ`）、线性代数（零空间、最小二乘、QP）、Python 与 NumPy。MuJoCo 的使用可以在阅读中现学。

## 第 1 步：机构和运动学（约 1 小时）

先看 `MJCF/robot.xml` 的刚体树和 `docs/architecture.md` 第 1 节。

要点：

- 每条腿是闭链五连杆，MuJoCo 里用“树 + 8 条 connect 约束”表达；
- 两个髋电机同轴，一个驱动大腿 AG，一个驱动曲柄 AB；
- 曲柄通过双平行四边形把运动传给小腿，所以小腿方向由曲柄决定；
- 关节角到腿空间量 `[L, φ]` 的映射在 `robot.py`。

练习：

1. 在 MuJoCo 里加载模型，打印 `nq / nv / nu / neq`，确认是 21 / 20 / 6 / 8。
2. 手动给一个髋关节角，调用 `robot.py` 的正运动学，算出 `L` 和 `φ`，再用 MuJoCo 的 `mj_kinematics` 验证轮心位置。
3. 改变曲柄角，观察小腿方向是否跟着转，理解“平行四边形”约束。

## 第 2 步：WBC 的行（约 2 小时）

看 `dynamics.py` 的 `RowSet` 和 `Task` / `Contact` / `Loop` / `Leg` 四个切片。

22 行的来源：

```
task    4 行：前进速度、横滚率、俯仰率、偏航率
contact 6 行：每轮切向 / 法向 / 横向
loop    8 行：每条腿 2 个 connect 点 × 机身 x、z
leg     4 行：L_R, φ_R, L_L, φ_L
```

练习：

1. 打印 `rows.rows.shape`，确认是 `(22, nv)`。
2. 对每个切片取一行，和 `data.qvel` 做内积，验证它等于对应量的速度。
3. 找 `leg_combination`，看共模/差模行是怎么由左右腿行组合出来的。

## 第 3 步：降阶模型（约 2 小时）

看 `model_builder.py` 的两个 builder。重点不是背公式，而是理解数值线性化的流程：

1. 当前位形 `mj_forward`；
2. 用 KKT 求约束加速度；
3. 对每个状态/输入加扰动，中心差分；
4. 得到 `A/B`，离散化。

练习：

1. 打印 8 状态模型的 `A`、`B`，对照状态顺序 `[s, v, θ, θ̇, ψ, ψ̇, δφ_c, δφ̇_c]` 和输入 `[f_R, f_L, τ_c]`。
2. 找 `unstable_pole`，理解为什么这台机器人是开环不稳定的。
3. 比较 6 状态和 8 状态的 `A` 矩阵，看腿角两行/两列多了什么。

## 第 4 步：MPC（约 3 小时）

看 `Algorithm/mpc/qp.py` 的模块说明和 `controller.py` 的 `MPCSettings`。

重点：

- 凝聚型 QP 把状态消掉，只留输入变量；
- 代价是状态误差 + 输入 + 输入变化率；
- 约束是逐轮箱型、偏航力矩、俯仰带、速度带；
- 俯仰带和速度带可能不可行，求解器会先松掉再解。

练习：

1. 打印 `Phi / Gamma / Psi` 的维度，验证 `X = Phi x0 + Gamma U + Psi`。
2. 取一个平衡点，令 `U = 0`，看预测状态是否自然发散（开环不稳定）。
3. 读 `_apply_zmp_reference`，理解 `zmp_split = 1.0` 时腿角参考是怎么写进状态 6/7 的。

## 第 5 步：WBC 求解器（约 3 小时）

看 `Algorithm/wbc/projection.py` 和 `wbc_limited.py`。

重点：

- 接触消去：把 `f_c` 消掉，得到接触零空间里的动力学等式；
- 硬约束是“接触加速度等式 + 欠驱动动力学等式”；
- 任务在硬约束零空间里分配；
- 严格优先级零空间法会饿死末级任务；
- WLS 同时分配，权重决定优先级；
- 限幅自洽用一维缩放保证 `τ` 与 `q̈` 一致。

练习：

1. 用 `--backend nullspace` 和 `--backend wls` 各跑一次前行，比较 `wbc_task_trace` 里各任务的残差。
2. 找到 `TASK_WEIGHTS`，把权重和任务顺序对上。
3. 构造一个力矩越限的工况，看 `scaling` 是否小于 1，`feasible` 是否为 True。

## 第 6 步：跳跃（约 4 小时）

先读 [jump.md](jump.md)，再看 `two_mass.py` 和 `control.py` 的 `dual_mass_flight_torque`。

重点：

- 两块的质量划分和耦合方程；
- 离地条件是 `F = −m1·g`，不是腿长阈值；
- 飞行段只规划 `z1(t)`，`z2(t)` 由动量守恒导出；
- 收腿/伸腿是曲线的自然结果，不是独立相位；
- 起跳段用质心五次多项式，端点是离地角动量目标；
- 落地段用质心五次多项式，终点是静平衡构型。

练习：

1. 用 `tools/two_mass_plan.py` 生成一组飞行计划，检查端点 `z1'(0)=z1'(T)=0`、`F(0)=F(T)=−m1·g`。
2. 从 `results/T1_baseline_s12c_h0.json.gz` 取 `leg_state`，画 `L(t)`，标出“伸—收—伸”三段，确认它们不是相位。
3. 计算触地时的两块速度，验证总动量守恒。

## 第 7 步：调试方法（约 2 小时）

读 [debugging.md](debugging.md)。重点不是记住六个问题，而是学会一套顺序：

1. 确认这次 run 用的是哪条通道、哪个开关；
2. 命令值与实测值逐拍对比，先归因规划/跟踪；
3. 检查评价工具的字段、下标、单位、符号、重复性；
4. 检查模型工作点是否还在线性化点附近；
5. 检查约束是否被顶住；
6. 最后才谈参数。

练习：

1. 跑一次 `s12c_h0`，从日志里找相位切换的时刻和核验值，确认它们和 `phase_transition` 记录一致。
2. 把 `--thrust-h-t` 从 0 改成 −0.20，比较触地 pitch 和离地角动量。这是设计输入变化，不是调参；记录两组的差异。
3. 用 `--model-variant held_leg` 跑前行，比较稳态速度和俯仰，理解 6 状态模型的限制。

## 建议的对照实验

下面这些是“开关对照”，不是调参，适合用来理解每个模块的作用：

| 对照 | 命令 | 观察 |
|---|---|---|
| 6 状态 vs 8 状态 | `--model-variant held_leg` / `leg_input` | 减速时腿角是否参与、减速距离 |
| 零空间 vs WLS | `--backend nullspace` / `wls` | 末级任务的残差和力矩 |
| 飞行段双质量块 vs 旧剖面 | `--flight-dual-mass` 开/关 | 触地 pitch、峰值法向力 |
| 起跳/落地计划 vs 旧阈值 | `--two-mass-takeoff` 开/关 | 离地状态、落地腿长、收敛时间 |
| MPC 名义法向力 vs 采样 | `--mpc-nominal-normal` 开/关 | 交还后是否自激振荡 |

做对照时保持其他开关不变，每次只改变一个条件。记录命令、数据文件、指标，不要凭视频印象下结论。

## 不建议做的事

- **不要先调参数。** 参数是最后一步，而且必须有依据。先确认模型、通道、评价工具没有问题。
- **不要用腿长/摆角当规划量。** 它们是导出量；规划它们会和两块动力学打架。跳跃相关的问题一律回到两块状态。
- **不要相信注释。** 这个项目的注释记录了大量历史决策，但代码改过之后注释可能没跟上。以代码和实测为准。
- **不要用单拍测量做约束。** 轮子微跳动会让采样法向力瞬间归零，进而产生自激振荡。用名义值或滤波值。
- **不要跨版本直接比较数字。** MuJoCo 版本、模型文件、质量参数变了，先跑回归再比较。
