# 轮腿跳跃落地规划

日期：2026-10-14
代码基线：git `835513c`。`control.py`、`loop.py`、`simulation.py` 已退回该版本。
本文只规划，不代表改动已经写入代码。

## 1. 要改什么

落地时同时满足三件事：

1. 轮子是最低点，腿连杆不先碰地。
2. 机体俯仰小到质心还在轮子附近，落地后不会向前滑、翻倒。
3. 腿角停在轮子能承力的角度，不追世界系几何垂直。

轮间隙不低于 0.200 m。这个高度用退回后的释放段和收腿参数，不另加高度目标。

## 2. 为什么不能继续原来的做法

离地后髋关节力矩没有地面接。把腿的摆动停住，角动量进入机体俯仰。
实测这条交换没有中间点：

| 版本 | 空中 phi | 落地世界系 phi | 落地 pitch | 落地后 |
|---|---|---|---|---|
| FL44 | 不控 | +0.586 rad | -0.117 rad | 腿角偏大 |
| FL53 | 追世界系 0 | +0.171 rad | -0.584 rad | phi 继续增大 |
| FL54 | 两段都追世界系 0 | +0.052 rad | -0.764 rad | pitch 到 1.55 rad，腿长越界中止 |

phi 收到接近 0 时，落地俯仰已经约 44 度。再交给落地控制器，质心不在轮子上方，轮子点接触撑不住，随后翻倒。

轮子惯量也补不完。单轮绕转轴惯量 0.000898 kg·m2，两轮合计 0.001796 kg·m2。
按可用转速，只能拿走大约两成俯仰角动量。

## 3. 借鉴轮圈腿，不搬参数

参照 `Algorithm/jump.py`。它不走 WBC，髋和轮各管一件事。

| 轮圈腿 | 作用 | 轮腿对应 |
|---|---|---|
| PREPARE：俯仰参考 -0.524 rad，由上层平衡控制执行 | 离地前把俯仰放到反方向 | 只在轮子着地、腿速已低时做，角度另定 |
| THRUST：髋角超过 2.0 rad 后反向满力矩 | 离地前把腿速刹住 | 腿长接近释放终点后先收腿速，再离地 |
| FLIGHT：髋收到 `land_hip = 0`，轮力矩管俯仰 | 腿形和俯仰分开 | 腿角收向 -0.1263 rad，不收向世界系 0 |
| 落地前 30% 飞行时间加大俯仰阻尼 | 触地时俯仰角速度接近 0 | 轮力矩在飞行后段加大阻尼 |
| RECOVER 只留 4 ms | 避免跳跃力矩和 WBC 交接再出一次冲击 | 触地后尽快把俯仰和腿角交还 WBC |

不搬的数：-0.524 rad、髋 10 N·m、轮 5 N·m、`land_hip = 0`。
这些是轮圈腿自己的机构和搜索结果。轮腿轮力矩上限是 ±6 N·m。

## 4. 改动

### 4.1 离地前刹腿速

文件：`wheel_leg_mujoco/gbc_mpc_wbc/jump.py`
位置：`JumpController.update` 的 `THRUST` 分支，292 到 308 行。

现在两条离地条件是轮地间隙大于 `LIFTOFF_GAP`，或腿长到达 `release_end`。
腿长到达后，增加腿速条件：`leg_length_rate` 的绝对值降到阈值以内才切 `FLIGHT`。
制动使用腿长通道的反向速度参考，不加 phi 力矩。

阈值起步用 0.3 m/s。没有单独辨识，第一次测试若刹不住或高度掉到 0.200 m 以下，停止，不继续减小。

### 4.2 离地前预倾

文件：`jump.py` 的 `COMPRESS_BRAKE`，282 到 290 行。

轮子还在地上、腿长已经到压缩终点、腿速接近 0 时，把俯仰参考从 0 改为后仰。
不放进 `COMPRESS`，也不放进正在蹬伸的 `THRUST`。
起步角度 -0.15 rad。在 `prepare` 超时或俯仰误差过大时不起跳。

-0.15 rad 是起步值。轮圈腿的 -0.524 rad 不使用。
最终角度等 4.3 测出的落地俯仰增量再定，不能提前按 0.76 rad 预倾。

### 4.3 飞行段腿角只收承力角

文件：`wheel_leg_mujoco/gbc_mpc_wbc/control.py`
位置：`flight_leg_profile_torque`，197 到 200 行。

退回后的代码上升段和下落段都调用 `_phi_force`，世界系参考会随 `l_ref` 变化。
改为固定世界系目标 `PHI_WORLD_REFERENCE = -0.1263`，不追 0。
机体系目标每拍投影：

```text
phi_body_ref = -0.1263 + pitch
```

增益保持 `KP_PHI = 20.9`、`KD_PHI = 1.67`。
上升段先保持这份控制。若测试显示上升段仍把俯仰打大，再只关上升段，不提前关。

### 4.4 俯仰交给轮子

文件：`jump.py` 的 `FLIGHT` 命令，367 到 371 行；`control.py` 369 行。

`JumpCommand.wheel_torque` 已有字段，但 `FLIGHT` 现在写 0。
`control.py` 在跳跃求解时把轮子通道清零，字段到不了轮子。

飞行段轮力矩改为俯仰 PD：

```text
wheel_torque = kp_w * pitch + kd_w * pitch_rate
```

符号取与当前负俯仰相反的方向，两轮同号，使机体俯仰减小。
预计飞行时间的后 30%，`kd_w` 乘 3，把触地时的俯仰角速度压小。
`kp_w`、`kd_w` 不能用轮圈腿的 20 和 6，轮腿限幅只有 ±6 N·m。
起步先取能在 0.3 rad 俯仰时不饱和的值，第一次测试只看方向和是否饱和，不调优。

`LANDING` 接触后的前几拍继续使用这条轮力矩，直到 WBC 接手。

### 4.5 落地后交还 WBC

文件：`wheel_leg_mujoco/gbc_mpc_wbc/loop.py`
位置：325 到 363 行。

现在 `LANDING` 由 `landing_buffer_torque` 独占 `data.ctrl`，WBC 被盖住。
改成：

1. 腿长缓冲保留，只写腿长通道。
2. 俯仰参考锁成触地第一拍的实际俯仰，不追起跳前的 0。
3. 腿角参考用 `-0.1263 + pitch_touchdown`，按触地俯仰投影，不使用机体系常数。
4. WBC 从触地第一拍写俯仰和腿角。缓冲和 WBC 写同一组执行器时，以 WBC 的俯仰、腿角为准。

`RECOVER` 不再要求俯仰回到 0 才交还。腿长回到标称邻域、轮子保持接触即可交还。

## 5. 不改

- `robot.xml` 的关节阻尼、摩擦、限位不改。
- `KP_PHI`、`KD_PHI`、腿长 PD 不改。
- 收腿下限、收腿速率、释放终点用 `835513c` 里的值，不使用后续试验改过的 0.20、0.26、0.5、1.5。
- 不把世界系 phi 目标设为 0。
- 不在离地后做预倾。

## 6. 一次测试看什么

五处一起改之后只跑一次，stage 名 `LAND1`。命令沿用现有跳跃诊断命令，高度、行程、时间参数不改。

| 项 | 合格 | 不合格就停 |
|---|---|---|
| 轮间隙 | >= 0.200 m | 低于 0.200 m |
| 落地俯仰绝对值 | <= 0.30 rad | 大于 0.45 rad |
| 落地俯仰角速度 | 绝对值 <= 0.5 rad/s | 触地后继续增大 |
| 落地后 0.5 s | 俯仰不再单调增大，腿长不越界 | 中止或翻倒 |
| 轮子与腿连杆 | 轮子最低 | 腿连杆低于轮子 |
| 轮力矩 | 未长时间顶在 ±6 N·m | 全程饱和 |

腿角只记录，不要求世界系为 0。
预倾角 -0.15 rad、刹腿速阈值 0.3 m/s、轮俯仰增益都是起步值。第一次结果只用来判断方向，不在同一次失败后连续改这三个数。
