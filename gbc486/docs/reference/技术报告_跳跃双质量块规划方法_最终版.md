## 0. 这份报告解决什么问题

轮腿机器人（GBC486，整机 14.546 kg，两轮 + 五连杆串联腿）的跳跃分四个相位：
压缩（蹲下）、蹬伸（弹起）、飞行（离地）、落地（触地缓冲）。
原方案的规划对象是"腿长 L"和"摆角 φ"两个**差值量**：

```
L = z2 - z1     （上块质心 z2 减去下块轮心 z1）
φ = 腿的摆动角
```

规划 L 和 φ 有一个根本问题：**L 是两个质量块位置的差值，无法区分是谁在动。**
比如"腿短了 10 cm"可能是轮子被拉高了 5 cm、也可能是机体被拽低了 5 cm，
两种情况需要完全不同的处理，但 L 上看不出来。

本报告描述的方法把规划对象从 L、φ 换成**两个质量块各自的运动**（位移、速度、角速度），
L 和 φ 变成计算结果而不是规划输入。跳跃全过程（起跳、飞行、落地）
都用两个质量块的动力学和运动学来描述。

## 1. 问题的原始来源：起跳时产生的不必要角动量

### 1.1 现象

原方案跳跃后，机体俯仰角（pitch）严重偏差：

| 指标 | 基线值 | 说明 |
|------|--------|------|
| 触地 pitch | −0.733 rad（−42°） | 触地时机体明显后仰 |
| 全程 max\|pitch\| | 0.795 rad | 飞行段达到更大值 |
| 触地俯仰角速度 | −1.55 rad/s | 机体仍在旋转 |
| 触地窗口峰值法向力 | 427.9 N | 落地冲击大 |
| 落地后收敛时间 T_max | > 3.0 s（发散） | 需要 WBC 花很长时间恢复 |

### 1.2 原因排查（§10.47）

把整机绕质心的角动量 H 按接触力矩分解，发现：

- 离地时 H = −0.353 kg·m²/s（机体在后仰方向积累了角动量）；
- **98% 的角动量来自蹬伸段（THRUST）**，不是压缩段或飞行段；
- 蹬伸段的角动量来自两项：
  - **法向力 N 乘水平偏置 d_n**（接触点与质心的水平距离）：第一项贡献大；
  - **切向力 Ft 乘竖直臂 z_c**：第二项贡献小。

关键发现：**d_n ≠ 0**。起跳时腿角被冻结（跳跃期摆角任务被摘除），
但腿长在变化，导致接触点相对质心的水平位置 d_n 不断变化。
实测 d_n 从 +15 mm 变到 −2 mm，几何解释度 96%。

用两个质量块的物理量描述：下块（轮子）和上块（机体）的相对水平位置 Δx 变化，
导致整机质心相对接触点偏移，法向力产生了绕质心的力矩。

### 1.3 角动量去了哪里

飞行段无外力矩，H 守恒在 −0.35 左右。角动量如何分配由两块的运动决定：

- 触地时 H = −0.34，其中**机体只占 11%**（0.037），其余 89% 在腿上；
- 基线方案触地时机体占 50%（0.177），角动量以机体旋转的形式表现出来。

所以问题不是"角动量太大"，而是**角动量以机体旋转的形式表现出来了**。
要降低触地 pitch，需要让角动量以"腿的摆动"而不是"机体的旋转"来体现。

## 2. 双质量块模型

### 2.1 质量块划分

| 块 | 组成 | 质量 | 说明 |
|---|---|---|---|
| 下块 m1 | 两轮 + 下段连杆（GH/OP，含轮毂电机） | 3.924 kg | 与地面接触 |
| 上块 m2 | 机体 + 其余全部 | 10.622 kg | 被腿支撑 |
| 整机 | | 14.546 kg | |

来源：MJCF `wheel_leg_mujoco/MJCF/robot.xml` 逐 body 质量求和。
质量比 k = m1/m2 = 0.3694，等效质量 μ = m1·m2/(m1+m2) = 2.865 kg。

### 2.2 两块之间的耦合

两块之间只有腿力 F（内力，正 = 撑开）。取竖直方向，轮子（下块）受：

```
m1·z1'' = N - m1·g - F                    （轮子牛顿方程）
```

整理出法向力：

```
N = m1·(z1'' + g) + F                     (2.1)
```

**离地条件**：N = 0 且 z1'' = 0，代入 (2.1)：

```
F = -m1·g = -38.5 N（两腿合计，单腿 -19.3 N）        (2.2)
```

即：腿必须在离地瞬间处于**拉力**，大小等于轮子自重。这是物理推论，不是人为设定。

### 2.3 飞行段的动量关系

飞行段两块之间只有内力 F，总动量守恒：

```
m1·z1'' + m2·z2'' = -(m1+m2)·g
z2'' = -k·z1'' - (1+k)·g
```

等价写法（L = z2 - z1）：

```
F = m2·(z2'' + g) = -m1·(z1'' + g) = μ·L''
```

直观结论：**腿在拉（F < 0）时机体每秒多掉 k·g = 3.62 m/s²；
腿在撑（F > 0）时机体每秒多升 3.62 m/s²。** 这是两块之间唯一的耦合。

### 2.4 力由逆动力学给出，不是弹簧刚度律

不需要拟合"腿像弹簧"的刚度律（如 F = a(l0-l)³ + b(l0-l)）。
直接由规划轨迹反解力：

```
F(t) = -m1·(z1''(t) + g)                  (2.3)
```

优点是少一层拟合误差；代价是力依赖 m1、m2 的准确值。

## 3. 规划方法：用两个质量块的运动代替 L 和 φ

### 3.1 飞行段：只规划轮子的竖直轨迹

取 u = t/T（归一化时间），形状函数：

```
f(u) = 64·u³·(1-u)³
f(0) = f(1) = 0,  f'(0) = f'(1) = 0,  f''(0) = f''(1) = 0,  f(0.5) = 1
```

规划轮子的绝对高度：

```
z1(t) = h · f(u)
z2(t) = z2(0) + v0·t - (1+k)·g·t²/2 - k·z1(t)    （由 2.3 的动量关系）
L(t)  = z2(t) - z1(t)                               （差值，不规划）
F(t)  = -m1·(z1''(t) + g)
```

端点二阶导为 0 自动满足两个条件：

- z1'(0) = z1'(T) = 0：轮子在离地/触地时刻竖直速度为 0；
- F(0) = F(T) = -m1·g：两端都满足 (2.2) 的离地/触地条件。

**收腿和伸腿不是动作**，是同一条曲线的自然结果：

```
L(t) 先升到 0.342（伸）、再降到 0.160（收）、再回到 0.280（伸）
```

规划里没有"收腿段"、"伸腿段"这些状态，也没有相位切换。

**T 和 h 由物理约束解出，不是调参量：**

- T（飞行时长）：触地时轮子回到地面（z1 = 0）且腿长等于落地腿长 L_td；
- h（幅值）：要求腿长最小值等于收腿下限 L_tuck = 0.16 m。

数值（v0 = 2.29、L0 = 0.283）：

| 项 | 值 |
|---|---|
| T | 0.342 s |
| h | 0.2323 m（轮离地间隙峰值） |
| L 区间 | [0.160, 0.342] |
| 峰值 \|F\| | 188 N（单腿 94 N） |

### 3.2 起跳段（THRUST）：五次多项式 + 角动量端点

起跳段规划整机质心的竖直轨迹，用五次多项式连接入口实测状态和离地目标状态：

- **入口**：质心位置、速度、加速度（实测）；
- **终点**：质心位置 D_td（静平衡构型高度）、速度 √(2g·h_target)、加速度 -g。

T（时长）在 [0.085, 0.120] s 内取"N 峰最小且全程 N ≥ 0、zc' ≥ 0"的值，
当前 T = 0.110 s、N 峰 514 N。

**水平方向与角动量**：端点速度由动量方程解出：

```
[∂zc/∂L   ∂zc/∂φ  ] [L'(T)  ]   [zc'(T)]
[∂H/∂L'   ∂H/∂φ'  ] [φ'(T)  ] = [H_t   ]
```

其中 H_t 是**离地角动量目标**（设计输入，默认 -0.20，可配 --thrust-h-t）。
H_t 越小，触地 pitch 越小（刚体项 0.89·H_t），代价是 THRUST 段腿摆更快、
离地后退速度更大。

**两块相对水平位移 Δx** 也用五次多项式规划，端点是静平衡流形上的 Δx_eq。

### 3.3 落地段（LANDING）：质心竖向五次

落地段规划整机质心的竖直轨迹，从触地（N = 0）到静止：

- **起点**：触地时质心位置 zc0、速度 vcz0（实测）、加速度 -g（N = 0）；
- **终点**：静止于 D(L_end)（L_end = 0.22 m 的静平衡高度），速度 = 加速度 = 0。

T 在 [0.060, 0.250] s 内取"N 峰最小"的值，当前 T = 0.179 s、N 峰 348 N。

**触地构型**：计划触地腿长 L_td = 0.34 m（不是站立腿长 0.28 m），
让落地时有缓冲行程。飞行段的触地构型用 D(L_td) 而不是站立 D_td。

### 3.4 三块规划的统一框架

| 段 | 规划量 | 端点条件 | T 的求解 |
|---|---|---|---|
| 起跳 | 整机质心 zc(t)、两块 Δx(t) | 离地 H = H_t、构型回静平衡 | N 峰最小 |
| 飞行 | 下块轮子 z1(t)（一条曲线） | 离地/触地 N = 0、腿长 = L_td | 物理约束解出 |
| 落地 | 整机质心 zc(t) | 终点静止于 D(L_end) | N 峰最小 |

**L 和 φ 全部是导出量**，由两块的运动反算：

```
L(t) = z2(t) - z1(t)              （腿长）
φ(t) = 两块连线与竖直方向的夹角     （摆角）
```

## 4. 控制实现

### 4.1 飞行段：力位混合

飞行段直接出力矩（无接触约束）：

```
F_cmd = F_plan(t) + 3000·(L_ref - L) + 150·(v_ref - L')
τ = J^T @ [F_cmd/2, F_φ]
```

3000/150 是既有增益，未改。**跟踪项必须保留**：纯前馈时约 15% 的模型误差
（静力学映射忽略杆件惯量）会积分成 68 mm 的 L 漂移。

### 4.2 起跳/落地段：WBC 任务

起跳和落地段仍走 WBC，但任务从"腿长/摆角"换成"两块物理量"：

| 段 | WBC 任务 | 说明 |
|---|---|---|
| THRUST | com_z（整机质心竖直）、dx_rel（两块相对水平）、L_d（差模腿长）、φ_d（差模腿角） | 替换原来的 length_R/L、angle_R/L |
| LANDING | com_z、dx_rel、L_d、φ_d + pitch（俯仰） | 同上 + 姿态 |

com_z 用整机质心的竖直雅可比（`com_vertical_row`），dx_rel 用两块质心的
水平差雅可比（`block_jacobians`）。

### 4.3 相位切换

- **THRUST → FLIGHT**：计划时钟到点 + 核验（两轮 N ≤ 0）；
- **FLIGHT → LANDING**：几何接触恢复；
- **LANDING → IDLE**：落地计划时钟到点。

### 4.4 MPC 轮力上限（§10.70 A）

交还后 MPC 的逐轮轮力上限用**名义法向力** M·g/2 = 71.3 N（上限 53.5 N），
不用单拍采样 N。原因：采样 N 会因轮子微跳动间歇性读到 0，导致 MPC
在两种解之间来回切换（40 ms 周期自激振荡）。

## 6. 与原方案的根本区别

| 维度 | 原方案 | 本方案 |
|---|---|---|
| 规划对象 | 腿长 L、摆角 φ（差值量） | 两块各自的位移、速度、角速度 |
| 收腿/伸腿 | 显式规划"何时收、收多少" | 曲线的自然结果，无状态切换 |
| 离地判据 | 几何触发（腿长阈值） | 物理触发（N = 0，由牛顿方程推出） |
| 角动量 | 不主动管理，事后表现 | 起跳端点设 H_t，飞行守恒，落地规划 |
| 触地构型 | 站立腿长 0.28 m | 计划触地腿长 0.34 m（有缓冲行程） |
| 落地缓冲 | WBC 腿长任务（无计划） | 质心竖向五次，终点静止于 L_end = 0.22 m |

## 7. 关键教训

1. **差值量不能区分是谁在动**。L 短了 10 cm 可以是轮子高了 5 cm 也可以是机体低了 5 cm。
   只有拆成 z1、z2 才能分别归因到"腿力通道"和"机体响应"。

2. **角动量不会被"消除"，只会被"转移"**。飞行段 H 守恒，能改变的是它在
   机体旋转和腿摆动之间的分配。要降低触地 pitch，在起跳时把 H_t 设小。

3. **离地条件是物理推论，不是人为阈值**。N = m1(z1''+g) + F = 0 给出
   F = -m1·g，腿必须在离地瞬间处于拉力。

4. **计划触地腿长应大于站立腿长**。L_td = 0.34 m（不是 0.28 m）让落地时有
   0.12 m 的缓冲行程，峰值力从 427.9 N 降到 347.8 N。

5. **交还后 MPC 的轮力上限不能用单拍采样 N**。采样 N 会因微跳动间歇性读到 0，
   导致 MPC 在两种解之间来回切换（自激振荡）。用名义值 M·g/2 即可。

6. **跟踪项不可省**。纯前馈时 15% 的模型误差（忽略杆件惯量）会积分成 68 mm 漂移。

## 8. 局限与未验证

1. **H_t 的偏差**。实测离地 H 与目标有约 12% 偏差（目标 0，实测 −0.026），
   导致触地 pitch 不是 0 而是 +0.14（变号）。来源未定位。

2. **离地后退速度**。H_t 越小，离地 vx 越负（H_t = 0 时约 −0.31 vs −0.23）。
   落地段水平速度计划（方案 B）未实施，交还时 vx 仍由 MPC 刹车。

3. **只验证了竖直跳跃**。侧向、带速度指令的跳跃、连续跳跃未测试。

4. **质量参数依赖 MJCF**。换轮、加配重必须重测 m1/m2。

5. **飞行段腿角跟踪能力**。KP_PHI = 20.9 在 1.69 rad/s 的摆速下正常跟踪，
   但更高速度未测试。

6. **待办：交还后的 pitch 姿态恢复（低头/抬头调整）**。H_t = 0 时触地 pitch
   不是 0 而是 +0.14（抬头，因实测离地 H 偏 -0.026），交还时 pitch = +0.144。
   MPC 接手后需要约 0.7 s 把它收回到 0。这个恢复过程目前没有被规划，
   完全交给 MPC 的自由响应。如果 H_t 的偏差能定位并消除，触地 pitch 接近 0，
   这个恢复过程就不存在。H_t = -0.20 时则是触地 pitch = -0.19（后仰），
   同样需要 MPC 花时间去扶。两个方向的根源相同：离地 H 与目标的偏差。

7. **待办：落地段水平速度计划（方案 B）**。交还时 vx 由 MPC 刹车，
   刹车幅度取决于触地 vx。如果落地段能把 vx 控制到接近触地值（而不是放任漂移），
   交还后 MPC 的摆腿刹车幅度会显著减小。方案设计见 §10.70 A4 和后续讨论，
   目前未实施。

## 9. 实现思路

### 9.1 初始化（每次启动一次）

用机器人模型在标称腿长附近扫一组静平衡位形，得到四张表（均以腿长为索引、
线性插值）：

- 质心到轮最低点的高度 D(L)——竖直规划和触地构型的换算表；
- 静平衡摆角 φ_eq(L)——两块连线回到平衡所需的摆角；
- 静平衡相对水平位移 Δx_eq(L)——两块水平计划的终点；
- 灵敏度系数：∂zc/∂L、∂zc/∂φ、∂H/∂L'、∂H/∂φ'——起跳端点速度方程的系数矩阵。

这些表是几何和静力学量，不含任何动力学参数，建表只需几秒。

### 9.2 每跳一次（进入相应相位时，用实测状态生成）

- **起跳计划**：读入压缩结束的质心位置/速度/加速度和两块相对水平位移/速度，
  生成竖直五次多项式和水平五次多项式，并解端点速度方程得到离地 L'、φ'。
- **飞行计划**：读入离地瞬间的质心竖速和轮最低点高度，解出飞行时长 T 和幅值 h，
  生成轮子竖直轨迹；腿长由 D(L) 表反查得到。
- **落地计划**：读入触地瞬间的质心位置和竖速，生成质心竖直五次多项式。

### 9.3 控制期（每拍）

- 飞行段：按计划轨迹算前馈力，叠加腿长 PD 跟踪，出力矩。
- 起跳/落地段：按计划轨迹构造 WBC 任务（com_z、dx_rel、差模腿长、差模腿角），
  由 WBC 求解力矩。
- 相位切换：由计划时钟触发，不用几何阈值。

### 9.4 设计输入汇总

| 输入 | 含义 | 建议值 |
|---|---|---|
| 目标跳高 | 质心抬升量 | 0.135 m（轮离地 ≥ 200 mm） |
| 触地腿长 L_td | 计划触地构型 | 0.34 m（比站立多 0.06 m 缓冲） |
| 落地终点腿长 L_end | 缓冲终点 | 0.22 m（再压缩 0.12 m） |
| 离地 H 目标 H_t | 离地角动量 | 0（触地 pitch 接近 0）或 -0.20（折中） |
| 收腿下限 L_tuck | 飞行段最短腿长 | 0.16 m |

所有值都是物理量，不是增益；改动只影响计划的形状，不影响控制器结构。

### 9.5 验证流程

- 每个方案先在副本上逐字应用替换、编译、跑自检，期望输出与实测一致后再部署；
- 回归：不带新开关时与基线逐帧一致；
- 单点：带新开关跑 12 s，检查三级判据（离地 ≥ 200 mm、T_max ≤ 3.0 s、pitch 削弱）；
- 不调参：所有增益沿用既有值，设计输入在方案中给定。
