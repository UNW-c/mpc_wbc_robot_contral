## 1. 架构差异与证据

| 项目 | 浙大文档 | 当前项目 |
|---|---|---|
| 上层控制 | p.7～8：十状态 LQR，状态含双腿摆角；四路虚拟力矩 | 六状态 MPC：[s,v,pitch,pitch_rate,yaw,yaw_rate]；输出优化状态与等效轮力 |
| 执行器映射 | p.45：两轮电机 + 四个腿关节电机，另有腿长控制及虚拟腿映射 | XML：两轮电机 + 两个曲柄电机，共四执行器 |
| 机构权限 | p.17、46：通过腿长与摆角协同实现近似独立的高度/摆腿 | 每侧轮心相对髋只有一个曲柄自由度，位置沿半径 0.06 m 的圆变化 |
| 模型调度 | p.7、16、39：腿长作参数，离线网格生成 K/A/B/Ud，在线拟合 | WheelMPC 构造时固定 ReducedModel 及离散预测矩阵，髋角目前只参与部分约束/几何监控 |
| 控制周期 | p.32：原平台任务每 1 ms 调度 | 当前解析时序 MPC 20 ms / WBC 4 ms；不能据原平台性能承诺本项目 1 kHz WBC |

XML 证据：`URDF_Model/mjcf/URDF_Model_plane.xml` 的 joint1/joint3 轴分别为 -y/+y，
joint2/joint4 轴分别为 +y/-y；轮关节安装在曲柄子体上。
因此“都是串联腿”不意味着动力学、输入符号、力矩权限相同。

旧 `docs/构型与控制逻辑.md` 中“零耦合”“与腿姿态完全解耦”只能用于描述无闭链传动，
不能用于断言运动学/动力学解耦：轮编码器测相对父连杆的转动，曲柄移动轮心，电机反作用力矩也进入机身动力学。

## 2. 最值得参考的部分

### A. 轮速运动补偿与统一反馈点：优先级 P0

**原文证据**：p.23 §10.2，式 (76) 将轮相对转速、连杆转速、机体俯仰角速度组合；
式 (77) 再消除伸缩、摆腿和机体转动造成的速度分量。p.25 式 (89) 对融合后的反馈速度积分。

**当前证据**：`Algorithm/estimator.py::_wheel_speed` 仅计算左右轮编码器差分乘半径并按轴符号平均。
`update` 中髋角只用于测量噪声调度，没有髋角速度、轮心平移补偿或接触可信度输入。
解析闭环使用 q/qvel 真值，既往测试通过并未验证这个估计器。

**推理**：轮关节装在曲柄上，关节相对转速不能在所有摆腿/俯仰工况下直接视作轮子的世界转速。
即使轮心速度解算正确，也必须从轮心换算到 MPC 所定义的机身参考点。

**移植方式**：重推本机构的轮—曲柄运动学，不复制原文连杆角公式。先确定反馈点 B，令轮心位置为
`p_C = p_B + R_WB r_BC(q)`，则

```
v_C = v_B + omega_B × (R_WB r_BC) + R_WB J_BC(q) qdot
```

在接触切向上结合 `v_C + omega_wheel × rho_contact = 0`，其中轮体角速度包含机身、曲柄和轮相对转动。
由编码器/IMU估计机身速度，再取航向前向分量；反馈行程积分估计速度，参考行程积分规划速度，保持两条链独立。
需明确切向无滑条件，不能用该关系强制解释空转/滑移数据。

**离线验收建议**：固定髋纯滚动、机身静止而曲柄运动、俯仰转动、左右不同髋角、正反向、偏航；
用手工构造一致运动的解析量检查坐标/符号与速度守恒，不需要启动 MuJoCo。

### B. 带加速度零偏状态的速度估计：优先级 P1，先完成 A

**原文证据**：p.24～25 §10.5，速度滤波状态为 `[v,a,b]`，轮速观测 v，IMU 观测 a+b。

```
F = [[1,dt,0], [0,1,0], [0,0,1]]
H = [[1,0,0], [0,1,1]]
```

**当前证据**：BodyStateKalman 状态为 `[pitch,pitch_rate,v]`；加速度直接推进速度，没有加速度零偏状态。
两者虽然都是三维滤波器，状态含义完全不同，不能只换矩阵而保留旧接口。

**建议**：姿态与前向速度估计分离，新增可替换的速度/零偏估计模块；以补偿后的轮速和同一点的前向加速度为观测。
轮速可信、dt 非零且模型成立时，两类观测可共同区分 a 与 b；持续滑移/长时间腾空时不能承诺相同可观性。
原文 q/qb/R 为其 1 ms 实车参数，不复制到本项目；本阶段不调参。

**不照搬式 (88) 的原因（本评审推导）**：将缺失轮速观测设为预测速度，只使该通道 innovation=0，
并不消除标准 KF 中 `P+ = P- - K H P-` 的信息更新。这样可能在没有新轮速信息时仍降低估计不确定度；
多通道联合更新中也不能笼统等同“纯惯性推算”。建议显式跳过无效轮速更新，保留可信 IMU 更新和过程噪声传播，
触地后再恢复真实观测。单轮接触应逐轮选取有效观测，不能统一当作双轮腾空。

### C. 接触检测、模式仲裁与切换交接：优先级 P0

**原文证据**：p.26～29，离地/触地检测分别定义、持续时间消抖、工况使能及超时；
p.32～35，检测→事件冻结→优先级仲裁→一次状态转移→执行；p.38～42，按进入来源初始化参考与接触模式。

**当前证据**：VelocityPlanner 已有 enabled/command_fresh/contact/valid，但 WheelMPC.solve 仍会继续求解，
未自动将 valid=False 转成完整模式退出；WBC 任务残差和饱和也尚未自动反馈参考层。

**建议**：增加独立的控制监督模块，输出带时间戳的模式/接触快照、参考有效性和任务使能，
一次仲裁同时决定 MPC 参考与 WBC 接触/任务集合。失能、单支撑、双轮腾空、稳定恢复分开处理，
执行器输出只有一个归属者；重置只在沿事件执行。

接触信号应将“是否建立约束”与“可用摩擦/法向力预算”分开：消抖保留接触状态时不能延用不可信的旧大载荷。
WBC 的硬接触释放需要正确切换约束行，不能套用 LQR 增益掩码或乘一个正数就宣称释放接触。
不能在 WBC 求解完成后简单把单轮力矩清零，否则其返回 qacc/接触力与实际输出可能不再一致。

原文的落地判据依赖主动伸腿后被地面压缩。本项目曲柄有死点、非单调几何，不具备同样的独立伸腿权限，
故仅借鉴检测结构，不复制腿长速度门限、伸腿推力和 Flight 增益掩码。
验证使用人工接触/异常信号：抖动、单轮卸载、双轮离地、同时事件、重新使能和超时，先做纯算法测试。

### D. 现有速度参考方案的小补充：主链保留，P1

**原文证据**：p.51 明确 §15 替代 §13.7 的旧参考生成描述；p.52 §15.1 区分 Track、BrakeToHold、
BrakeToReverse、Hold，使用物理加减速界、摇杆零位滞回，反向指令不必等待实测速度完全停下才响应。

**当前对应**：已有斜坡、跨零精确积分、BRAKE/HOLD、单步提交与恢复重置；反向在参考速度过零后继续，
不会等待实测速度停车。当前输入零区为单阈值，日志只区分 DRIVE/BRAKE，未显示独立的反向制动原因。

**可选补充**：输入层对模拟摇杆加零位滞回，保留键鼠直接零/非零语义；参考诊断增加制动原因，
无需改变动力学控制结构。规划速度/加速度与位置导数保持一致；继续使用我们周期内事件的精确积分。

原文 acmd 为一拍速度增量/dt，属于区间平均加速度；本规划器 acceleration 是分段轨迹节点的瞬时加速度。
两者在周期中途到速或跨零时可不同；若以后引用摆腿前馈，必须先声明用哪一种，不能直接视作同义字段。
原文 p.39 的“误差大就冻结位置积分”不能独立照搬到仍输出非零速度的 MPC 轨迹中。

### E. 静态工作点与随构型变化的模型：优先级 P0/P1

**原文证据**：p.15～16 §6～7 先求静态输入 Ud，再按双腿长度网格生成模型与控制器；p.39 在线调度。

**当前证据**：WheelMPC 一实例固定 A/B；ReducedModel.from_mujoco 的源码明确注明测得的是髋自由工作条件，
实际 WBC 下髋行为仍需匹配；原始两髋 ctrl 相加的俯仰漂移符号也尚待确认。

**建议**：先定义本机构的静态工作点、接触条件与髋任务，再在同一条件下建立降阶模型；
必要时按 `(q_R,q_L)` 建表，而非只按平均高度。模型调度时一致更新离散模型、预测矩阵、漂移、
兜底增益和历史视界处理；接近奇异点、表外输入与切换连续性须验证。

原文最小二乘静态配平承认存在残差。本项目不能把非零动力学残差称作精确平衡，
更不能将其前馈直接加到已经含重力偏置 h 的 WBC 输出上而重复补偿。最小二乘采用 QR/SVD 等数值方法，
不照抄显式求逆 `(B.T B)^-1 B.T`。多项式拟合只是一种实现方法，不能保证插值后稳定与可控。

### F. 高度/转弯能力限制与功率规划：后续 P1/P2

**原文证据**：p.44～45 §13.13 以 `|v*omega|`、重心高度、偏航加速度和实测载荷转移率 LTR 限制转向；
p.54 §15.5 随高度收紧速度/加速度；p.29～31 §12 将稳态功率降额放在速度指令层。

**建议**：保持 MPC/WBC 分层，在参考生成之前限制运动需求，并用 WBC 实际任务残差、接触载荷和执行器余量监督。
只限制输入命令还不能保证 MPC 纠偏时的预测/实际转向满足约束，需检查实际及预测 v、omega、载荷；
在 MPC 中处理乘积约束时还要考虑其非线性，不能直接称为现有线性箱约束的一行。
本项目接触点会纵向错开，不能把原文横向轮距简式当完整三维防翻条件，需重新核验支撑轴与质心几何。
LTR 仅在法向力可靠、总支撑足够时有意义，接近零支撑不能直接除法。

功率系数须来自本机；原文依赖超级电容支持瞬态峰值，不适合作为没有能量模型时的硬功率保证。
当前先不新增能量模块，更不在 WBC 输出后统一缩放力矩破坏已求得的平衡与动力学一致性。

## 3. 当前明确不移植的内容

1. 十状态 LQR 全套模型/增益、五连杆映射、六电机虚拟腿输出链：机构和权限不同。
2. 独立腿摆角前馈（§8、§15.2）：本机单曲柄不能同时指定腿长和摆角；不能把它等价为机身俯仰前馈。
   作者在 p.16、18、53 也明确说明移植旧机标定的偏差及振荡/超调风险。
3. 极慢位置误差配平积分（p.53～54 §15.3）：用户已接受当前有界小残差，暂不加积分环或调参。
   原文约 10 s 的慢环并不自动证明与平衡环“完全解耦”，需要验证耦合稳定性。
4. 强制左右轮—腿竖向作用力相等（p.6、12）：原文自己指出这是模型闭合近似；不用于覆盖 WBC 的实际载荷分配。
5. 跳跃/翻身/过坎的开环力矩、阶段阈值与输出叠加：权限和行程不匹配，且超出当前平地算法阶段。
6. 原文 1 ms 调度、KF 噪声、PID 数值及功率系数：不是本项目的验证依据。

## 4. 与现有待办的对应及建议顺序

| 顺序 | 建议范围 | 不启动仿真的验收方法 |
|---|---|---|
| 1 | 统一 MPC/里程计的反馈点、坐标与符号；补偿曲柄/机身对轮速的影响 | 解析运动学恒等式、正反向及左右差动样本 |
| 2 | 控制监督、参考 valid 与 WBC 任务/接触切换闭合 | 事件序列、单次转移、暂停/恢复、力矩/qacc 一致性测试 |
| 3 | 实际 WBC 残差/饱和回传参考层 | 注入不可达运动任务、持续饱和、恢复，检查不误用 scaling |
| 4 | 接触门控的独立速度/零偏滤波 | 合成偏置、缺失轮速、单轮空转；检查误差与协方差一致性 |
| 5 | 工作点/模型随曲柄构型变化的设计，转向能力约束 | 离线矩阵及几何检查；涉及 MuJoCo 的辨识或装配另行审批 |

这些是本次阅读后的待实施建议，不构成新的算法替换授权。
建议优先评审 1～3，之后才评估是否有必要更换估计器；当前 MPC/WBC 主架构和有界残差处理决定保持有效。
仿真接入仍需单独提交方案并获用户批准。
