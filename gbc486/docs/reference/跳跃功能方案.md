## 1 腿长上下限（用户选压缩行程的依据）

用解析腿运动学 + 模型逆运动学（`R.solve_leg`）逐点扫描，受限关节为 `jAB / jAG / jGH`（右腿；
被动关节 jBE/jEC/jCF 不受限，不计）。闭链残差全程 `~7e-8`，说明扫描位形有效。

| 腿长 L [m] | 0.110 | 0.115 | 0.120 | 0.135 | 0.150 | 0.280 | 0.420 | 0.430 | 0.440 |
|---|---|---|---|---|---|---|---|---|---|
| 最小关节余量 [rad] | **-0.019** | +0.012 | +0.039 | +0.109 | +0.179 | +0.660 | +0.110 | +0.013 | **-0.096** |
| 受限关节 | jAG | jAG | jGH | jGH | jGH | jAG | jGH | jGH | jGH |

结论：

```
机械极限（余量 = 0）：  L ∈ [0.112, 0.432] m
留 0.10 rad 关节余量：  L ∈ [0.134, 0.422] m      <- 建议的工作范围
现有模型网格：          L ∈ [0.140, 0.420] m      <- 正好落在建议范围内
```

**压缩行程可用范围**（`s_c = L0 - L_c`，`L0 = 0.28`）：

| 压缩终点 `L_c` | 0.134 | 0.140 | 0.150 | 0.160 | 0.180 | 0.200 |
|---|---|---|---|---|---|---|
| 压缩行程 `s_c` | 0.146 | 0.140 | 0.130 | 0.120 | 0.100 | 0.080 |
| 该处关节余量 [rad] | 0.10 | 0.132 | 0.179 | 0.225 | 0.313 | 0.387 |

即 **`s_c` 最大可取 0.146 m**（到 0.10 rad 余量线）；建议区间 **0.12 ~ 0.14 m**（余量 0.225~0.132 rad，
且第 2 节显示深层压缩更省力矩）。

## 2 可行性（本次实算，±40 N·m）

### 2.1 单位竖向力 -> 关节力矩系数 `c(L)`

| L [m] | 0.16 | 0.18 | 0.22 | 0.26 | **0.28** | 0.32 | 0.36 | 0.40 | 0.42 |
|---|---|---|---|---|---|---|---|---|---|
| `c(L)` [N·m/N] | 0.1236 | 0.1369 | 0.1553 | 0.1644 | **0.1660** | 0.1641 | 0.1554 | 0.1391 | 0.1273 |

**系数在站立腿长 0.28 处最大**（两端更小），所以"释放段伸到 L0 就离地"没有额外力矩代价；
设计上取 `c = 0.1660` 为界，逐拍仍需用**实测位形**算 `J`（两端与中间差 21%~34%）。

### 2.2 h = 100 mm 的力与关节力矩

```
v_takeoff = sqrt(2 g × 0.100) = 1.4007 m/s
F_leg     = m(g + v²/(2 κ s_c)) / 2
tau_peak  = F_leg × c(L)      # 逐点取行程两端较大者
```

| `s_c` | `L_c` | `F_leg`（κ=1） | 峰值 `|tau|`（κ=1） | 余量 | `F_leg`（κ=0.7） | 峰值（κ=0.7） | 余量 |
|---|---|---|---|---|---|---|---|
| 0.10 | 0.18 | 142.7 N | **23.69** | 41% | 173.3 N | **28.77** | 28% |
| 0.12 | 0.16 | 130.8 N | **21.72** | 46% | 156.3 N | **25.95** | 35% |
| 0.14 | 0.14 | 122.3 N | **20.31** | 49% | 144.2 N | **23.94** | 40% |

κ = 质心抬升 / 腿长行程（第 8.3 节，仍待算，只会落在 0.7~1.0）。

**结论：±40 N·m 下 100 mm 目标可达，最差情形（κ=0.7、s_c=0.10）仍有 28% 力矩余量。**
按用户要求（"不严格要求精确高度，差不多就行"），验收看功能是否跑通，不追高度数值。

## 3 架构：跳跃是独立模块，也是独立状态

### 3.1 模块（`gbc_mpc_wbc/jump.py`，纯计算）

| 结构 | 职责 |
|---|---|
| `JumpConfig` | 目标高度、压缩行程、力参考量（第 7 节参数表） |
| `JumpObservation` | 一跳观测：时间、实测腿长/腿长率、接触、姿态 |
| `JumpCommand` | 输出：相位、目标等效力（竖直）、目标腿长、腿力矩前馈、轮力矩指令、**冲突功能关闭标志** |
| `JumpPlanner` | 状态机 + 闭式反解；`start()` / `update()` |

不持有模型/数据/MPC/WBC/采样器/输出级；不写执行器；不含等待型定时器。
装配点仅两处：`control.py`（力进 WBC、冲突功能关闭）与 `loop.py`（相位与输出）。

### 3.2 跳跃期关闭清单（用户第 4 条）

| 关闭项 | 冲突原因 | 正常控制中是否必需 |
|---|---|---|
| 扰动补偿 | 与跳跃力争用同一条 `external_force` 通道（`supervision.py:283`） | 是 |
| MPC 腿摆角前馈 `sample.acceleration[3]` | MPC 腿长线性化在快速变腿长时发散 | 是 |
| MPC 腿摆角反馈 `sample.state[6]/[7]` | 与 WBC 腿摆角误差控制打架 | 是 |
| 蹬伸段 WBC 轮相关任务 | 轮力矩经地面摩擦给机体水平反力，污染竖直蹬伸 | 是 |
| 离地档脱离控制器 | 飞行段需要按跳跃指令出力，脱离控制器会零输出 | 是（意外离地时必需） |

跳跃结束统一恢复。

## 4 状态机（判据全是测量量或闭式量）

```
IDLE ──起跳指令──> COMPRESS ──L_meas <= L_compress_end──> THRUST
                                                             │
                                        两轮接触丢失（真离地）或 L_meas >= L_release_ceiling
                                                             v
                                                          FLIGHT ──接触恢复──> LANDING
                                                                                 │
                                             L_meas 回到 L0 邻域且姿态/速度进入正常包线
                                                                                 v
                                                                             RECOVER ──> IDLE
             任意状态：非有限量 / 关节余量越界 ──> ABORT
```

| 状态 | 施加的力 | 腿长目标 | 轮力矩 | 退出判据 |
|---|---|---|---|---|
| IDLE | 无 | L0 | WBC | 起跳指令（事件） |
| COMPRESS | 无前馈 | `L_compress_end` | WBC 俯仰任务 | `L_meas <= L_compress_end` |
| THRUST | 竖直等效力 F（第 5 节） | `L_release_ceiling`（≥L0） | 跳跃模块独占 | 两轮接触丢失；兜底 `L_meas >= L_release_ceiling` |
| FLIGHT | 无 | 冻结 | **开环力矩**（第 4.1 节） | 接触恢复 |
| LANDING | 无 | 从落地腿长柔顺收回 L0 | 跳跃模块 | `L_meas` 进入 L0 邻域 |
| RECOVER | 无 | L0 | 交还 WBC | 姿态/速度进入正常包线 |

**COMPRESS 段刻意不加前馈力**：压缩由 WBC 跟一条腿长斜坡完成，此段机体下降、重力被地面反力吸收；
再叠加额外力只会去挤下限位。

### 4.1 飞行段处理（按用户指示）

1. **触发**：沿用离地检测逻辑（两轮判为离地）——飞行段由**离地检测触发**，不由腿长阈值触发；
2. **断开控制器**：WBC 不求解、MPC 不参与输出；
3. **电机命令**：模型执行器是 `<general gainprm="1">` 纯力矩型，**没有位置控制能力**，按用户"不能就开环力矩"取
   **开环力矩**分支。具体取"零阶保持离地瞬间力矩"还是"恒零"，请在 D4 指定（建议零阶保持，力矩连续、无突变）。

## 5 力的反解（闭式，无迭代）

### 5.1 竖直等效力

```
v_takeoff = sqrt(2 g h)                    # 目标高度 -> 离地速度
a         = v_takeoff^2 / (2 κ s_c)        # κ = 质心抬升/腿长行程；s_c = 压缩行程
F_total   = m (g + a)                      # 施加在机体上的竖直等效力（整机）
F_leg     = F_total / 2                    # 对称两腿
t_thrust  = v_takeoff / a                  # 加速时间（导出量，不是设定值）
```

用户第 1 条（已按更正理解）：**固定 `s_c` 可解出 `F`；固定 `F` 可解出 `s_c`**。首次测试走"固定 `s_c` 反推 `F`"。

### 5.2 竖直力 -> 关节力矩（力雅可比）

```
F_L = F_z cos φ
F_φ = -F_z L sin φ        # φ0 = -0.1263 rad，该项占比很小
tau = J^T @ [F_L, F_φ]    # J = ∂(L,φ)/∂q_act，2×2，已消被动关节速率（LegKinematics.jacobian）
```

每拍用**实测位形**算 `J`；可行性判据 `max|tau| <= 40 N·m`（现值），超限即报告不可行，不迭代。

### 5.3 力作用线与姿态

不使用预倾。蹬伸段是否给机体灌入角动量，取决于竖直等效力作用线是否过质心，由几何与质心位置**算出**；
若不过质心，角动量由 THRUST 段轮俯仰力矩与腿摆角共同处理（第 6 节），不在起跳前预置姿态。

## 6 WBC 集成：力进模型，不对抗

已核实（`supervision.py:253-283`、`wbc/task_qp.py:236-241`、`wbc/sns.py:182-186`、`wbc/weighted.py:61-64`）：
求解器统一按 `M q̈ + h = Sᵀτ + Jᵀf + external` 处理，`task_qp` 内实现为 `h ← h − external`。

- **注入**：`external = selectionᵀ @ τ_jump`（6 维执行器前馈，4 条腿非零，轮按 D7）；
- **输出**：`ctrl = τ_wbc + τ_jump`；
- 语义：模型里已知这份力，WBC 求解"扣除它之后的剩余需求"，不会用腿长阻尼去抵消。

配套两条（否则 WBC 仍会对抗）：

1. **腿长任务参考跟跳跃**：`wbc.py::tasks` 的腿长任务参考是标称 `L0`，跳跃期改由 `JumpCommand` 提供目标腿长；
2. **蹬伸段轮力矩独占**：THRUST 段 `ctrl[4:6]` 只来自跳跃模块（相位门控，非权重），代码里加断言。
