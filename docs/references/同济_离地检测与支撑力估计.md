## 1. 支撑力的来源：任务空间反馈（§3.2）

当雅可比可逆时，由电机反馈力矩反算任务空间广义力：

```
[F0; Tp] = (J_leg^T)^(-1) @ [tau_f; tau_r]
```

- 这组反馈用于**估算地面支撑力、离地状态和执行器实际负载**；
- 保护条件：若 `|det(J_leg)| < ε_J`，则停止求逆并把反算结果置为安全值；
  直接对病态矩阵求逆会把很小的电流噪声放大成巨大的虚拟力。

## 2. 支撑力估计（§6.5）

由 VMC 反算量估计地面法向支撑力。忽略较小项时，**单腿的腿端竖直分量**：

```
P_i = (F0_i + F_s,i) * cos(theta_l,i) - (Tp_i / l_i) * sin(theta_l,i)
```

再**加入轮质量的重力与垂向惯性项**：

```
F_N,i ≈ P_i + m_w * (g + a_w,z)
```

符号（按上下文推断，原文未逐一给出）：`F0` 前馈项、`F_s` 腿部力项、`theta_l` 腿倾角、
`Tp` 髋关节力矩、`l` 腿长、`m_w` 轮质量、`a_w,z` 轮垂向加速度。

## 3. 离地判定（§6.5）

- **带滞回的双阈值**：
  - 支撑力**低于下阈值** → 判为**离地**；
  - 支撑力**高于上阈值** → 判为**恢复接地**；
  - 目的：避免在阈值附近**逐帧抖动**。
- **跳跃模式的补充条件**：结合**动作相位**与**腿长条件**判断，
  **不能只凭一帧支撑力切换**。

## 4. 离地门控：检测到离地后的控制处理（§5.4）

原文要点："检测到整车或单腿离地时，轮地约束不再成立。此时继续用 `s, s_dot, phi, phi_dot`
反馈驱动轮子没有物理意义，还会造成落地瞬间轮速过高。"

LQR 接口支持**按状态贡献做门控**：

1. **轮力矩的全部地面运动项清零**；
2. **髋力矩保留两条腿自身的角度和角速度稳定项**（保留空中的腿部姿态约束）；
3. 车轮位移、偏航和俯仰对髋力矩的贡献**清零或降权**；
4. **落地后重新对齐积分目标，再恢复完整反馈**。

## 5. 误差处理的相关约定（§5.4，与离地门控同节）

- 位移误差可做**有限幅度限制**，防止长时间累计后给出过大恢复力矩；
- 偏航误差使用**环形差**：`e_phi = wrap(phi* - phi)`；
- 俯仰位置误差限制在模型有效的**小角度范围**；
- 速度项一般**不做积分**，以免传感器偏置长期积累到目标。

## 6. 工程实现提示（原文）

- 当前在线状态重构**持续估计两侧支撑力和单腿离地标志**；
- **整车离地门控是否接入 LQR，由对应车辆完成落地阈值标定后启用**——
  即阈值没有给出具体数值，需**实车标定**；
- 该文档的处理前提是**基于 VMC 反算支撑力**（力控腿），与纯位置/力矩接口的
  实现方式不同，落地阈值与门控项需要按本机接口重新设计。
