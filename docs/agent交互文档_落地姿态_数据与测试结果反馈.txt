3. 常用取数口径（防止口径不一致）
================================================================

- 触地时刻：`jump.phase` 首次等于 `LANDING` 的那一帧（当前基线 t=1.7470）。
- "触地后"：`t >= 触地时刻` 的帧集合（当前基线 1252 帧）。
- `airborne_zero` 帧：`output_source == "airborne_zero"`。
- `motion_enabled=True` 帧：`decision.motion_enabled` 为真（等价于 `mode == "ground"`）。
- 腿长不对称：`dL = leg_length_R - leg_length_L`。
- 轮间隙：`wheel_gap[i]`（米，负值为压入）。
- 几何接触：`contact_geometry`（逐轮 bool，来自 MuJoCo 接触对，与力矩无关）。
- 非轮-地接触数：`contact_geometry_other`（腿连杆砸地看这个）。
- 腿长越界阈值：> 0.430 m 或 < 0.114 m。
- 飞行段最大轮间隙：`t` 在 FLIGHT 相位内的 `wheel_gap` 最大值。
