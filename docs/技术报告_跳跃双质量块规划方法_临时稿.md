## 0. 结论摘要

1. 把跳跃看成"两个质量块 + 它们之间的可变长连接"，规划对象从腿长
   换成两块各自的绝对运动，腿长（以及收腿/伸腿）变成计算结果。
2. 力不再是控制器的输出，而是由规划的轮子加速度反解：
   `F = -m1*(z1'' + g)`，再经 `tau = J^T[F_L, F_phi]` 落到髋电机。
3. 飞行段只需要一条 C2 连续的曲线；时长 T 与幅值 h 由两个物理约束解出，
   不是调参量。
4. 离地判据用轮子的牛顿方程（`N = m1*(z1''+g) + F`，N=0 即
   `F = -m1*g`），与"切段判据"（轮子静止且平衡）分开。
5. 实测（12 s，`--flight-dual-mass`）：触地 pitch −0.7328 → −0.5394（−26.4%）、
   max|pitch| 0.7945 → 0.5916（−25.5%）、触地窗口峰值力 427.9 → 201.8 N
   （−52.8%）、触地 omega −1.55 → −0.32（−84.5%），无 ABORT。
6. 触地 pitch 之所以降下来，不是因为"消除了角动量"，而是把角动量
   从机体挪到了腿上：飞行段总角动量守恒在 −0.34 kg·m²/s，
   触地时机体只占 11%。
7. 观测层是本方法附带的能力：z1、z2 分别可测，误差可直接归因到
   腿力通道或机体响应，不再只能看一个混在一起的腿长。
8. 二维形式（把腿看成二维弹簧阻尼器、在 x/y 上规划）已试一次并失败：
   根因是把轴向刚度 3000 N/m 当成切向刚度用（切向本应是 267 N/m），
   横推力饱和、phi_dot 冲到 16 rad/s。修正方案只换 phi 的参考、不动增益。
9. 未验证：伸腿段、状态机简化、x 方向的相位整形、极坐标前馈（离心/科氏）。
10. 已知缺陷：`z1 = z2 - L` 不是轮心真实高度（飞行段漂 27.5 mm），
   导致"提前 33 ms 触地"，P5/P6 的未过项由此而来。

## 1. 出发点：为什么不再规划腿长

### 1.1 腿长是一个差值

设轮子（下质量块）与机体（上质量块）的绝对高度分别为 z1、z2，腿长

```
L = z2 - z1
```

规划 L 等于直接规定"差值怎么变"，但差值的两端是谁动的、动了多少，
在 L 上看不出来。

### 1.2 一个具体例子

同一段飞行里：

- 轮子被多拉高 5 cm（腿力给大了）
- 机体被多拽低 5 cm（同一记力的反作用）

在 L 上都表现为"腿短了 10 cm"，无法区分是谁的问题。而这两种情况
需要完全不同的处理：前者改力的大小，后者改力的时机。

实测证据见第 6 节：把 L 拆成 z1、z2 之后，误差立刻分到两个通道上。

### 1.3 换空间带来的第二个好处：力变成设计变量

规划 L 时，力是跟踪控制器的输出，机体受到的冲量是事后结果；
规划 z1 时，力由 `F = -m1*(z1''+g)` 反解，机体反应在规划阶段就已知。

## 2. 物理模型

### 2.1 质量块划分

| 块 | 组成 | 质量 |
|---|---|---|
| 下块 m1 | 两轮 + 下段杆件（GH/OP，含轮毂电机） | 3.924 kg |
| 上块 m2 | 其余全部 | 10.622 kg |
| 合计 | | 14.546 kg |

来源：MJCF `wheel_leg_mujoco/MJCF/robot.xml` 逐 body 质量求和。

### 2.2 轮子的牛顿方程与离地条件

取 z1 向上为正。轮子受三个竖向力：地面法向 N、自重 m1·g、
腿对轮子的反作用（若腿对上块作用力为 F，正=撑开，则对轮子的反作用为 −F）：

```
m1*z1'' = N - m1*g - F          (1)
N = m1*(z1'' + g) + F           (2)
```

接地时 z1=0、z1'=0。只要 N>0，轮子就被压在地上——**推力（F>0）只会把
轮子压得更紧**。分离条件是 N=0 且 z1''=0：

```
F = -m1*g = -38.5 N（两腿合计，单腿 -19.3 N）        (3)
```

即：腿必须在离地瞬间处于**拉力**、大小等于轮子自重。这条不是人为设定，
是 (2) 在 N=0 时的推论。

### 2.3 飞行段的动量关系

飞行段两块之间只有腿力 F（内力），总动量守恒：

```
m1*z1'' + m2*z2'' = -(m1+m2)*g
z2'' = -k*z1'' - (1+k)*g ,   k = m1/m2 = 0.3694
```

等价写法：

```
F = m2*(z2'' + g) = -m1*(z1'' + g) = m_red*L'' ,   m_red = 2.865 kg
```

由此得到一个直观结论：**腿在拉（F<0）时机体每秒多掉 k·g = 3.62 m/s²；
腿在撑（F>0）时机体每秒多升 3.62 m/s²。** 这是两块之间唯一的耦合。

### 2.4 力由逆动力学给出，不是弹簧刚度律

论文的虚拟弹簧写成 `F = a*(l0-l)^3 + b*(l0-l)`，再积分得轨迹。
本工程的腿由电机驱动，不需要先造一条弹簧律再解 ODE，直接反解：

```
F(t) = -m1*(z1''(t) + g)                             (4)
```

两者在"给定轨迹求力"上等价，但 (4) 少一层拟合误差。代价是力依赖
m1、m2 的准确值，换轮或加配重必须重测。

### 2.5 与论文的差别（必须写清，否则会误用）

论文平台的机构设计让"机身与腿部整体质心位于轮部与髋关节中心连线附近"，
所以高度调整时俯仰本身就变化很小；它的腾空段还用轮部力矩控俯仰
（轮/机惯量比允许）。本构型两条都不成立：

- 曲柄/五连杆让质心随腿态移动，飞行段实测质心相对轮心的水平偏置
  最大 44.6 mm；
- 飞行段轮力矩实测 0.00 N·m，轮/机惯量比约 127:1，轮子无法定俯仰。

因此本工程飞行段唯一能改俯仰的通道是腿的摆角（把角动量在机体与腿之间
重新分配），这一点与论文不同。

## 3. 规划方法

### 3.1 飞行段一条曲线

取 `u = t/T`，形状函数

```
f(u) = 64*u^3*(1-u)^3
f(0)=f(1)=0,  f'(0)=f'(1)=0,  f''(0)=f''(1)=0,  f(0.5)=1
```

规划轮子的绝对高度：

```
z1(t) = h * f(u)
z2(t) = z2(0) + v0*t - (1+k)*g*t^2/2 - k*z1(t)      （由 2.3 的动量关系）
L(t)  = z2(t) - z1(t)                                （差值，不规划）
F(t)  = -m1*(z1''(t) + g)
```

端点二阶导为 0 带来两个自动成立的条件：

- `z1'(0) = z1'(T) = 0`：轮子在离地与触地时刻竖直速度为 0；
- `F(0) = F(T) = -m1*g`：两端都满足 (3) 的干净条件。

### 3.2 两个量都由约束解出

**T（飞行时长）**：触地时轮子回到地面（z1=0）且腿长等于落地腿长 L_td：

```
L0 + v0*T - (1+k)*g*T^2/2 = L_td
=> T = [v0 + sqrt(v0^2 - 2*(1+k)*g*(L_td - L0))] / ((1+k)*g)
```

实测输入（L0=0.283、v0=2.29、L_td=0.28）给出 T = 0.342 s。

**h（轮子绝对轨迹幅值）**：要求腿长最小值等于收腿下限 L_tuck：

```
L(t) = L0 + [v0*t - (1+k)*g*t^2/2] - (1+k)*h*f(u)
min L(t) = L_tuck  =>  h = (0.478 - L_tuck)/1.3694
```

L_tuck = 0.16 m 给出 h = 0.2323 m。

注意 (1+k) 这个系数：`L` 里 z2 含 `-k*z1`，漏掉它会把 h 高估 1.37 倍。
本报告初版就犯过这个错，已更正。

### 3.4 收腿与伸腿不是动作

上表里 L 先升到 0.342（伸）、再降到 0.160（收）、再回到 0.280（伸），
全部是同一条曲线的自然结果。规划里没有"收腿段"、"伸腿段"、"团身"
这些状态，也没有任何相位切换。

### 3.5 二维弹簧阻尼器：正交分解

腿不是"一根只能伸缩的杆"，而是两块之间的一个**二维弹簧阻尼器**。
它的自然坐标不是 x/y，而是沿腿轴与垂直腿轴：

```
e_L（沿腿轴，伸缩）    k_L = 3000 N/m     c_L = 150 N·s/m    带宽 32.4 rad/s
e_t（垂直腿轴，横摆）  k_t = KP_PHI/L^2    c_t = KD_PHI/L^2   带宽  9.0 rad/s
```

L=0.28 时 k_t = 267 N/m、c_t = 21 N·s/m。两条通道的刚度差约 11 倍、
带宽差约 3.6 倍——腿在竖直方向很硬，在横摆方向很软。

x/y 只是这两条通道的世界系投影。腿的两个自由度 (L, phi) 与轮子相对髋的
平面位置 (x, z) 一一对应：

```
x = -L*sin(phi),  z = -L*cos(phi)
Jp = d(x,z)/d(L,phi) = [[-sin(phi), -L*cos(phi)],
                        [-cos(phi), +L*sin(phi)]] ,  det(Jp) = L
(F_L, F_phi) = Jp^T * (F_x, F_z)
```

det(Jp)=L 在 [0.16, 0.34] 内恒非零，所以两组量完全等价、可逆。
换坐标不改变任何物理，只改变"用哪个量做误差与目标"。

### 3.5.1 用 x 做什么：相位

实测力矩为 `F_z(t)·d(t)`，其中 d = 质心 x − 轮心 x。把 d(t) 平移、
形状与幅值不变（即角动量存储不变），力矩冲量随之变化：

| d(t) 平移 | ∫F·d dt |
|---|---|
| −20 ms | −0.1924 |
| 0（现状） | −0.1485 |
| +20 ms | **−0.0551（−63%）** |
| +40 ms | +0.0547（过冲，符号反了） |

同一个摆幅、把轮子横向偏移推迟约 20 ms，力臂力矩冲量降 63%。
这个量在旧坐标系里无法单独定时（d 是 phi 的副产品），只有把 x 当成
规划量才能定它的相位。

### 3.5.2 一次失败：把轴向刚度搬到切向（重要教训）

第一版实现按字面写成

```
F_x = m1*x_dd + 3000*(x_ref - x) + 150*(x_ref' - x')
```

即把轴向的 3000/150 直接用在 x 上，并把 phi 的 PD 整个删掉。
结果（12 s，两个 case 均无 ABORT 但主判据全崩）：

| 项 | s1pd（只换 z 规划） | x_k1.0 | x_k1.2 |
|---|---|---|---|
| M1 触地 pitch | −0.5394 | −0.8513 | −0.8224 |
| M2 max\|pitch\| | 0.5916 | 0.8871 | 0.8723 |
| M3 峰值力 | 201.8 N | 123.5 N | 121.4 N |
| M4 触地 omega | −0.32 | −4.21 | −3.83 |
| 飞行段 \|omega\| 峰 | 5.01 | 13.17 | 12.87 |
| 飞行段 tau 峰 | 12.4 N·m | 40.0（116 帧饱和） | 40.0（110 帧饱和） |
| 飞行段 phi_dot 峰 | 6.92 | 16.22 | 15.91 |

k=1.0 与 k=1.2 差别很小，说明崩的原因不是相位，而是刚度口径：
用 3000 N/m 控 x，等于把切向刚度放大 11 倍——
x 误差 30 mm 就产生 90 N 的横推力，换算成髋力矩 27 N·m，
叠加规划力后必然打满 40 N·m，phi 被猛推，phi_dot 冲到 16 rad/s，
姿态反而更差。

结论：**二维弹簧阻尼器的两条通道各有自己的刚度和阻尼，不能互换。**
x 的控制不应另造一套增益，而应复用切向原有的那套（即 phi 的 PD）。

### 3.5.3 修正方案：不删 phi 的 PD，只换它的参考

```
L_ref(t)   = L0 + travel - (1+k)*z1(t)                      （不变）
phi_ref(t) = phi_w_ref(t) + pitch
phi_w_ref(t) = -asin(x_ref(t) / L_ref(t))
x_ref(t)   = x0 + A_x*f(u^k),   x0 = 捕获帧的 x_rel
F_L   = 3000*(L_ref - L)   + 150*(v_ref - Ldot)
F_phi = 20.9*(phi_ref - phi) - 1.67*phi_dot
```

即：力仍在 (L, phi) 坐标里给，x 只作为 phi_ref 的生成器。
"x 也有自己的弹簧阻尼"这件事由 phi 的 PD 承担，不需要新增增益。

A_x = 0.040 m（实测横向偏移峰值 44.6 mm），k = 1.2（把形状峰从 u=0.5
推到 0.5612，对应实测最优平移 +20 ms）。k=1.0 作为等价性验证：
此时 phi_ref 与 phi_eq 差别很小，结果应与 s1pd 接近（M1-M4 差 < 5%）。

### 3.5.4 口径约定（本轮踩过的三个坑）

| 量 | 定义 | 注意 |
|---|---|---|
| F | 腿对**上块**的作用力，正=撑开（向上） | L 方向口径 |
| F_z | 腿对**轮子**的竖直力，正向上 | 与 F 反号：F_z = −F |
| F_L | 两腿合力的轴向分量 | 每腿给 F_L/2 |
| F_phi | 绕髋的合力矩 | 每腿给 F_phi/2 |
| P8 | ∫(x_wheel − x_com)·F_z dt | 用 F_z（轮子口径），不是 F_L |

早期把 F_z 写成 −m1(z1''+g)、把 P8 用 F_L 算，都属口径混淆，
已作废。

### 3.6 极坐标分解：这才是正确的自然坐标

3.5 的"径向/切向"用一个更准确的框架可以写死：腿绕髋关节转动，
轮心相对髋的位置天然是**极坐标**，

```
p = (L*sin(phi), -L*cos(phi))        L = 半径（两块之间的距离）
                                     phi = 极角（两块的角位置关系）
```

x/y 只是这个极坐标在固定系里的投影，而**半径 L 会变**，所以同一个 x
在不同的 L 下对应的角度完全不同。这就是 S1-x' 失败（3.5.2、文档 10.14）
的几何根因：x 偏移 40 mm，在 L=0.28 时是 8 度、在 L=0.16 时是 28 度，
而平衡角在该处只有 14 度。把它当成"锚点没选好"只是表面，坐标系选错才是根。

**极坐标把两个耦合项显式写出来。** 轮心相对髋的加速度：

```
a_r = L'' - L*phi'^2            径向：离心项
a_t = L*phi'' + 2*L'*phi'       切向：科氏项
```

于是腿必须供给的广义力（m1 为下块质量，含两轮）：

```
F_L = m1*(L'' - L*phi'^2 + g*cos(phi_w))          径向，与 L 共轭
tau_phi = m1*L*(L*phi'' + 2*L'*phi' + g*sin(phi_w))  切向，与 phi 共轭
```

其中 `m1*L^2*phi''` 是切向惯量项、`2*m1*L*L'*phi'` 是科氏、`m1*L*g*sin(phi)` 是重力力矩。

**实测这两项有多大（s1pd 飞行段）：**

| 项 | 峰值 | 等效力误差（m1 折算） |
|---|---|---|
| 离心 `L*phi'^2` | 8.2 m/s² | **32 N** |
| 科氏 `2*L'*phi'` | 18.8 m/s² | **74 N** |
| 对照：计划 F 峰值 | | 188 N |
| 对照：\|z2''\| 峰 | 2.2 m/s² | |

当前的前馈只用了竖直方向 `F = -m1*(z1''+g)`，这两项一项都没算。
科氏项折算成力已经和主力量级相当；离心项也不能忽略。
这正是两件事的解释：

- 纯前馈版（文档 10.5）为什么漂 68 mm——除了刚度口径，模型里还缺这两项；
- s1pd 的模型误差为什么约 15%——PD 一直在替这两项补差。

**通道结构不变。** `F_L` 与 `tau_phi` 本来就是径向/切向的广义力，
所以这不是新执行器、不是新增益，只是把前馈算准：

```
F_L     <- m1*(L_ref'' - L*phi'^2 + g*cos(phi_w))
tau_phi <- m1*L*(L_ref''... 见上式，用参考量替代实测速率)
```

工程上更稳的写法是"参考的加速度项 + 实测的速率项"：
`L_ref''`、`phi_ref''` 取规划值，`L'`、`phi'` 取实测值（因为耦合项
对速率敏感，用实测更准），其余保留原有 PD 作为残差修正。

**与起跳段的关系：** 起跳段轮子接地（z1=0、phi 几乎不动），
`L' = z2'`、`phi' ≈ 0`，两个耦合项都接近 0，所以 S2 不受影响；
极坐标前馈是飞行段的事，排在 S2 之后做（S2.5）。

### 3.7 控制对象：轮子质量块的二维运动（而不是摆角）

3.6 把坐标换成了极坐标，但控制量还留在 phi 上。再往前一步：**控制对象是
轮子这个质量块的二维运动，摆角是解算结果。**

```
径向：位移 L、速度 L'、加速度 L''          （已在做：z 规划 + 轴向 PD）
切向：位移 s = L*phi、速度 v_t = L*phi'、加速度 a_t
解算：phi = s/L ,  phi' = v_t/L ,  phi'' = (a_t - 2*L'*phi')/L
```

### 3.7.1 为什么这样更对：角动量 = 半径 × 切向速度

绕髋角动量

```
H_leg = m*L^2*phi' = m*L*v_t
```

同一个半径上"多转一点"与"半径缩短后同样的转速"，对应的角动量完全不同：

| L | 保持 H = −0.35 需要的 v_t | 需要的 phi' |
|---|---|---|
| 0.34 | −0.26 m/s | −0.77 rad/s |
| 0.16 | −0.56 m/s | **−3.48 rad/s** |

即 **1/L 的齿轮比**：腿越短，同样的角动量需要越快的切向速度。

### 3.7.2 这解释了收腿中段 pitch 为什么会变差

现在的控制是"角度参考"（`phi_ref = phi_eq(L)`），等价于把 phi' 当受控量、
不管 L 在变。而收腿把 L 从 0.34 掉到 0.16，同样的 phi' 对应角动量按 L² 缩：

| L | phi' = 1 rad/s 时的 H |
|---|---|
| 0.34 | +0.454 |
| 0.28 | +0.308 |
| 0.20 | +0.157 |
| 0.16 | +0.100 |

**收腿本身就在把角动量从腿倒给机体**（L 减半，H 掉到 1/4）。机体要接住
这部分只能转起来——这就是 omega 峰出现在收腿最深处的原因，不是 PD 调得
不好，也不是规划曲线不好。

### 3.7.3 控制律（一行，不需要新增益）

给定角动量目标 `H_tgt(t)`（本轮取"保持离地时的总角动量"）：

```
v_t_ref(t) = H_tgt(t) / (m*L_ref(t))
phi_ref(t) = phi0 + ∫ H_tgt / (m*L_ref^2) dt
tau_t_ff   = dH_tgt/dt                  （保持时 = 0）
```

phi0 取捕获帧实测摆角，H 取捕获帧由模型算出的总角动量。
按现有 z 规划（L 0.283→0.16→0.28）离线积分：phi_ref 摆幅 0.529 rad
（基线实测 0.44，同量级），phi' 从 −1.11 到 +3.48 rad/s。
phi 的 PD 保留做残差跟踪，增益不动。

### 3.7.4 两条通道的"权限"（离线预筛，见 tools/path_prescreen.py）

要设计控制，先得知道哪个量有权限。用圆周坐标逐条路径算 F_r、tau_t：

| 通道 | 手段 | 角动量传递 ∫tau_t dt | 判定 |
|---|---|---|---|
| 径向 | 收腿深度 L_tuck 0.14→0.26 | −0.911 → −0.881 | **几乎没有权限** |
| 切向 | 极角叠加 0→0.30 rad | −0.222 → +0.019 | 斜率 +0.81 (N·m·s)/rad，**可正可负** |

另外一条重要事实：径向路径自带很大的切向冲量（P-L 的 ∫tau_t = −0.910，
是纯切向路径的 4 倍），因为 `phi_eq` 是 L 的函数——**收腿必然伴随一次
大的切向冲量**，它不是选出来的，是几何带的。

所以控制分配是：径向负责"收多少"（行程与间隙），切向负责"角动量怎么给"
（其 1/L 齿轮比由 3.7.1 的解算自动处理）。

## 4. 控制实现

### 4.1 力位混合，不是纯前馈

飞行段的力：

```
F_cmd = F_plan(t) + 3000*(L_ref - L) + 150*(v_ref - L')
tau   = J^T @ [F_cmd/2, F_phi]
```

3000 / 150 是既有增益，未改。跟踪项不是可选项：实测纯前馈时，
约 15% 的模型误差（静力学映射 + 飞行段杆件惯量）会积分成 68 mm 的 L
漂移，142 ms 就撞到腿长下限并 ABORT；加上跟踪项后 L 偏差落到
|−8| mm 量级。

规划力本身不能用位置误差替代：在 u=0.1 处规划要求 F=−186 N（拉），
而位置误差 `L_ref-L = +34 mm` 会让 PD 给出 +102 N（推），符号相反。

### 4.2 接触相位仍交给 WBC

压缩、蹬伸、落地仍走原有 WBC 路径（腿长任务 + `com_vertical` 权重）。
新层在接触相位只提供任务参考，不直接出力矩；否则与 WBC 抢同一对髋关节。
飞行相位无接触，才允许直接出力矩。

### 4.3 两个判据必须分开

| 判据 | 含义 | 条件 |
|---|---|---|
| 离地（物理） | 地面给不了那么大的力 | `N_est = m1*(z1''+g) + F <= 0` 连续 k 拍 |
| 切段（控制） | 状态与计划的段边界一致 | `z1' = 0` 且 `z1'' = 0` |

N_est 的数据来源：`mj_objectVelocity` / `mj_objectAcceleration` 读轮子的
z1'、z1''，`F = solve(J.T, tau_leg)`。接地段实测 N_est 比真实 N 低 7.5%
（171 vs 185 N/轮，静力学映射忽略杆件惯量，论文同样忽略），够判穿越；
离地后该式失效（实测 −227 N 而真实 N=0），只用于接地→离地这一段。

现状对照（基线 base01）：切段发生在 N=373 N（2.6 倍整机重量），
腿力从 +159 N 跳到 −241 N（分离条件的 6 倍），轮子是被这一记拉力
"拔"离地面的。这解释了为什么基线的离地伴随巨大的相对速度。

## 6. 实测结果

### 6.1 S1-PD 主判据（12 s，`--flight-dual-mass`）

| 判据 | 基线 | 本次 | 变化 |
|---|---|---|---|
| M1 触地 pitch | −0.7328 | −0.5394 | 改善 26.4% |
| M2 max\|pitch\| | 0.7945 | 0.5916 | 改善 25.5% |
| M3 触地窗口峰值力 | 427.9 N | 201.8 N | 改善 52.8% |
| M4 触地 omega | −1.55 | −0.32 | 改善 84.5% |

相位完整（FLIGHT→LANDING→RECOVER→IDLE），ABORT 0，腿长 [0.1564, 0.3376]，
stop_reason 为空。回归（不传开关）与 base01 逐帧差 0。

### 6.2 剩余角动量

绕整机质心的 H（y 分量，MJCF 逐帧重算）：

| 时刻 | pitch | omega | H (kg·m²/s) |
|---|---|---|---|
| 离地 1.426 | −0.0021 | −0.023 | −0.3530 |
| 触地 1.735 | −0.5397 | −0.323 | −0.3389 |

- H 守恒在 −0.34（起跳带来的，本方法不改它）；
- 触地时机体占 `0.1142*0.323 = 0.037`，即 **11%**；其余 0.30 在腿上；
- 基线对照：omega −1.55 → 机体占 0.177（50%）。

**结论：M4 降 84% 不是因为消除了动量，而是把它从机体挪到了腿上。**

### 6.3 phi 通道真实贡献

飞行段右腿分解（由 tau 与 J 反算，5 ms 采样）：

```
F_phi ∈ [−5.4, +3.0] N·m，峰值 5.4
∫F_phi dt = +0.006 N·m·s → Δomega ≈ 0.05 rad/s
```

phi 控制力矩对机体的角冲量只有 0.05 rad/s，可以忽略；phi 的摆角
（−0.124 → −0.565，0.44 rad）主要来自耦合前馈 `0.052*F_L`。
所以"phi 控制本身有害"这个假设不成立；它是存动量的执行手段。

### 6.4 力臂与相位

| t | F_L | phi_world | d(mm) | F·d | omega |
|---|---|---|---|---|---|
| 1.457 | −79.8 | −0.106 | +2.9 | −0.2 | +0.35 |
| 1.577 | +50.3 | +0.126 | −42.4 | −2.1 | −4.94 |
| 1.727 | −79.1 | −0.040 | −0.3 | +0.0 | −0.15 |

力臂峰值 44.6 mm，乘积峰值 2.2 N·m，`∫F·d dt = −0.1485`。
要产生 −4.94 rad/s 的 omega 暂态需要约 0.56 N·m·s，力臂项只解释 26%；
其余来自腿自身的角动量转移。

### 6.5 二维形式（S1-x）的结果：失败，但定位明确

见 3.5.2 的表。四条主判据全部劣于 s1pd，tau 打满 116 帧，
飞行段 |omega| 峰从 5.01 涨到 13.17，phi_dot 峰从 6.92 涨到 16.22。

归因：不是坐标系换算错，也不是相位选错（k=1.0 与 k=1.2 几乎一样），
而是把轴向刚度 3000 N/m 当成切向刚度用，把原本 267 N/m 的软通道
硬化了 11 倍，导致横推力饱和。

因此：**"换分析坐标"本身没有让方案变差；把两条通道的刚度混用才让它变差。**
修正方案（3.5.3）只换 phi_ref，不动任何增益。

## 7. 局限与未验证

**7.1 `z1 = z2 - L` 有几何误差（已知缺陷）**

L 是髋-轮距离，不是竖直落差；腿有摆角时两者不等。实测差值在飞行段
漂 27.5 mm：

| t | z2−L | 轮心真实 z | 差 |
|---|---|---|---|
| 1.426 | −0.0592 | +0.0769 | +0.1361 |
| 1.601 | +0.1734 | +0.2983 | +0.1249 |
| 1.735 | −0.0327 | +0.0758 | +0.1086 |

计划把"z1 回到捕获帧的 0"当作触地条件，而实际接触发生在 z2−L 还差
27 mm 时——这就是实测"提前 33 ms 触地、z1'=−0.712"的来源，
不是控制误差。修法：z1 改用轮心真实高度（`mj_objectPosition`），
或用 `z2 - L*cos(phi_world) - 常数`。会改变 T 与 h，尚未做。

**7.2 纯前馈会漂 68 mm**，必须带跟踪项；跟踪项吃掉了约 15% 的模型误差，
但模型误差本身没有辨识。

**7.3 只验证了飞行段。** 起跳段的干净释放（把 F 收尾到 −m1·g）、伸腿段、
状态机简化（PLAN_READY→PLAN_RUNNING→DONE）都未实施。当前离地条件
仍是几何触发（N=373 N 时切段）。

**7.4 x 方向方案未实施。** 3.5 节的 −63% 是用实测 F(t)、d(t) 离线平移
算出来的，不是仿真结果；Jp 映射、去 phi PD、x 跟踪都还没写。

**7.5 触地 pitch 的下限受守恒角动量约束。** H=−0.34 是起跳带来的，
要更低只能降低离地速度（与跳高平方相关）或改变 H 在机体/腿之间的分配。

**7.6 二维弹簧阻尼器的两轴刚度不能互换（本轮最贵的教训）。**
轴向 3000 N/m、切向 267 N/m（L=0.28），相差 11 倍。任何在 x/y 坐标系里
重新分配刚度的实现，都必须先把刚度换算回自然坐标再做。

**7.7 质量参数依赖 MJCF。** 换轮、加配重必须重测 m1/m2，否则 F_plan
有系统偏差。

**7.8 离地角动量全部产生在第二推力段（本轮新增，只读实测）**

把离地前的地面段按接地力矩拆成两项（法向力乘水平偏置、切向力乘竖直臂），
三个 run 的结论一致：

| run | 第一段净冲量 | 第二段净冲量 | 全程 | 其中第一段的两项 |
|---|---|---|---|---|
| base01 | +0.0094 | +0.3377 | +0.3471 | +0.4277 / −0.4183 |
| s1pd | +0.0094 | +0.3383 | +0.3477 | +0.4277 / −0.4183 |
| s2_on | +0.0094 | +0.3434 | +0.3528 | +0.4277 / −0.4183 |

读法：

- 第一段（N≈192 N）两项各自很大但**几乎精确抵消**，净冲量只剩 0.009；
- 第二段（N 从 192 涨到 373 N）法向项继续累加，而切向力掉到 0，抵消失效，
  于是 97% 的角动量在这里产生；
- 与释放策略无关（s2_on 与 s1pd 只差 0.005）。

两质量块模型的理想压缩是纯轴向的，对应两个可测条件：

```
d_n = 0     接触点在质心正下方
F_t = 0     地面切向力为零（不驱动轮）
```

现在系统是 d_n = 14.7 mm 且 F_t ≈ −4.5 N（互相抵消），属"凑巧平衡"。
两者必须同时为零；只压一个会把 H 推到反向且更大（实测 −0.42）。

注意实现前提：跳跃期 WBC 不消费 MPC 轨迹（`sample=None`）且轮任务被摘除，
所以**任何只改参考的方案在跳跃期内都是空操作**（S6 已实测确认：逐位相同）。
